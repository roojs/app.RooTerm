# 0.6 — Delete connection closes open sessions

**Status:** proposed

**Pointer:** `docs/guide-to-writing-plans.md` — **Checklist for plans**; Vala via **`docs/coding-standards-router.md`**. Build: **`docs/build-rules.md`**.

**ℹ️** Builds on **`docs/plans/0.3-session-states-history-guake.md`** exit hold / 30s close, and **`OpenSession`** / {@link SshTerminal.select} countdown.

---

## Purpose

- **🔷** Deleting a connection must **exit** its open terminal sessions.
- **🔷** **Visible** (selected) tab → start the **30s** close countdown immediately.
- **🔷** **Not visible** → stay until the user focuses that tab, then the **30s** countdown starts.
- **🔷** With several tabs open: visible tab counts down and closes → next tab is selected → its countdown starts → repeat until none left (then the host page goes empty as today).
- **🔷** `⏳` Wire delete in {@link HostTreeMenu} to that exit path; reuse existing EXITED / `close_in(30)` behaviour — do not invent a parallel close system.
- **💩** Exit mechanism: store VTE spawn `pid` on {@link Terminal}, `Posix.kill` on delete so `child_exited` still runs (same path as SSH dying).
- **ℹ️** Reconnect-after-exit skipping login is a **bug**, not this plan — `docs/bugs/2026-07-30-reconnect-skips-open-session-login.md`.

---

## Current behaviour

- **ℹ️** Delete (`HostTreeMenu`): `conn.deleted = true`, tree remove, save — **sessions left running**.
- **ℹ️** SSH child exit → {@link SshTerminal} `state = EXITED`; hint fed to VTE.
- **ℹ️** Focused exit: {@link OpenSession} `exited` → `close_in(30)` when `selected`.
- **ℹ️** Unfocused exit: hold; {@link SshTerminal.select}`(true)` while `EXITED` → `close_in(30)`.
- **ℹ️** Tab X / `close_page` without `close_confirmed` → `close_in(30)` (live session, not EXITED).

---

## Proposed behaviour

- **🔷** On confirmed delete of a host / LXC (anything with open `conn.sessions`):
  - `Posix.kill` each session’s `child_pid` (SIGTERM)
  - do **not** start `close_in` on every tab at once
- **🔷** `child_exited` → EXITED as today; if `selected`, `close_in(30)` on the terminal itself (not only via {@link OpenSession}).
- **🔷** Other tabs → EXITED, no countdown until selected (existing `select` path).
- **🔷** After each tab closes, `Adw.TabView` selects another → `HostPage.wire` → `select(true)` → next **30s** — natural chain.
- **🚫** `set_pty(null)` in the delete handler.
- **🚫** New helper methods (`kill_child`, `exit_sessions`, …) — inline only.
- **💩** Group delete (empty of children) — no sessions; no extra work.

## 1. Store spawn pid

### 1.1 `src/Terminal.vala` — field `child_pid`

**Why:** VTE only gives the child pid in the spawn callback; delete needs it to signal the process.

**Where:** class body of {@link Terminal}, after `public Vte.Terminal terminal;`.

**Depends on:** none.

#### Add — after `public Vte.Terminal terminal;`

Spawn pid for {@link Terminal.spawn} children; ``-1`` when none / exited. Used to SIGTERM on connection delete.

```vala
		/**
		 * Child pid from the last successful {@link spawn} (``-1`` if none).
		 */
		public int child_pid = -1;
```

### 1.2 `src/SshTerminal.vala` — `spawn()` callback stores pid

**Why:** Fill {@link Terminal.child_pid} after SSH spawn succeeds.

**Where:** `spawn()` — success branch of `spawn_async` callback.

**Depends on:** §1.1.

#### Remove
```vala
				(term, pid, error) => {
					if (error != null) {
						GLib.warning("ssh spawn failed: %s", error.message);
						var fail = "spawn failed: " + error.message + "\r\n";
						this.terminal.feed(fail.data);
						return;
					}
					GLib.debug("ssh pid=%d name=%s", pid, this.connection.name);
				}
```

#### Replace with

Same callback; set `this.child_pid` on success (and clear on failure).

```vala
				(term, pid, error) => {
					if (error != null) {
						this.child_pid = -1;
						GLib.warning("ssh spawn failed: %s", error.message);
						var fail = "spawn failed: " + error.message + "\r\n";
						this.terminal.feed(fail.data);
						return;
					}
					this.child_pid = pid;
					GLib.debug("ssh pid=%d name=%s", pid, this.connection.name);
				}
```

## 2. Focused EXITED always starts 30s

### 2.1 `src/SshTerminal.vala` — `child_exited` → `close_in(30)` if selected

**Why:** Countdown must not depend on {@link OpenSession} still being alive after login. Unfocused tabs still wait for `select`. `close_armed` ignores a second start from {@link OpenSession}.

**Where:** ctor — end of `child_exited` lambda, after `this.exited();`.

**Depends on:** none (independent of pid; do with §1 or alone).

#### Remove
```vala
				this.terminal.feed(hint.data);
				this.exited();
			});
```

#### Replace with

Clear `child_pid`, emit `exited`, then start 30s when this tab is selected.

```vala
				this.terminal.feed(hint.data);
				this.child_pid = -1;
				this.exited();
				if (this.selected) {
					this.close_in(30);
				}
			});
```

### 2.2 `src/Jobs/OpenSession.vala` — drop duplicate `exited` → `close_in`

**Why:** §2.1 owns focused countdown; keep ctor free of a second handler.

**Where:** `OpenSession` constructor body after `base(…)`.

**Depends on:** §2.1.

#### Remove
```vala
		public OpenSession(MainWindow window, Connection connection)
		{
			base(window, connection);
			var ssh = (SshTerminal) this.terminal;
			ssh.exited.connect(() => {
				if (ssh.selected) {
					ssh.close_in(30);
				}
			});
		}
```

#### Replace with
```vala
		public OpenSession(MainWindow window, Connection connection)
		{
			base(window, connection);
		}
```

Also shorten the class docblock line that says OpenSession calls `close_in` on exit — point at {@link SshTerminal} `child_exited` instead (**💩** doc-only).

## 3. Delete kills session children

### 3.1 `src/HostTreeMenu.vala` — delete confirm kills pids

**Why:** User deletes the host → every open session’s child must exit so EXITED / 30s chain runs.

**Where:** `delete_btn.clicked` → `alert.response` success path, after `tree.remove(conn)`, before `config.save()`.

**Depends on:** §1.1–1.4, §2.1.

#### Remove
```vala
					conn.deleted = true;
					this.window.config.tree.remove(conn);
					try {
						this.window.config.save();
					} catch (GLib.Error e) {
						GLib.warning("config save failed: %s", e.message);
					}
```

#### Replace with

Mark deleted, remove from tree, SIGTERM each live session child (no `close_in` here — `child_exited` / `select` own the countdown).

```vala
					conn.deleted = true;
					this.window.config.tree.remove(conn);
					for (var i = 0; i < conn.sessions.get_n_items(); i++) {
						var term = (Terminal) conn.sessions.get_item(i);
						if (term.child_pid <= 0) {
							continue;
						}
						Posix.kill(term.child_pid, Posix.Signal.TERM);
					}
					try {
						this.window.config.save();
					} catch (GLib.Error e) {
						GLib.warning("config save failed: %s", e.message);
					}
```

## Suggested order

1. §1.1–1.4 pid field + spawn + `posix` pkg.
2. §2.1–2.2 focused `close_in` on `child_exited`; drop OpenSession duplicate.
3. §3.1 delete → `Posix.kill`.
4. Manual: three tabs on a host → delete → 30s → next → 30s → page empty; unfocused host → switch to it → countdown starts.
