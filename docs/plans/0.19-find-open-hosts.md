## Purpose

- **🔷** Reorganise **finding and opening** hosts: working view vs hunting for a new host.
- **🔷** While working you mostly want **currently open** rows, in tree context, not the full available tree.
- **🔷** Hunting a new host is **search + toggle**, not a pulldown.
- **🔷** LXC tabs sit on the **host machine’s page**.
- **🔷** Park **expand/collapse persist** (0.14) while this map is in play.
- **🔷** `✔️` Phase 1 — Open-only tree + bottom toggle (so you can still reach all hosts).
- **🔷** `✔️` Phase 2 — Empty-space hint; open or select → revert.
- **🔷** `✔️` Phase 3 — Search filters the tree; delete the popover.
- **🔷** `✔️` Phase 4 — LXC tabs on the parent host page.
- **🔷** `⏳` Phase 5 — Stop expand persist; expand so the visible row can be seen.

## Phase 1 — Open-only tree + toggle

- **🔷** `✔️` If anything is open, the tree shows **only** that open set (plus those parents).
- **🔷** `✔️` Bottom **toggle** (with search) switches open-only / all — otherwise Phase 1 is stuck in the open set.
- **🔷** Open rows stay **in tree context**: an open LXC child still shows its parent host (and that host’s parent group); hide everything else.

### Today (before this phase)

- **ℹ️** Left pane: full nested `Host.Tree` (`connections.json`).
- **ℹ️** Search sits under the tree (`Host.SearchPulldown`). No open-only / all toggle.

### Behaviour

- **🔷** A row is **open** if that connection has at least one tab (`sessions` non-empty).
- **🔷** Show a row if it is **open**, or it is a **parent** of an open row (the parent need not have its own tab).
- **🔷** Each node keeps ``children_open``: how many child rows have a tab. Open/close walks ``parent`` and bumps the count.
- **🔷** Hide all other hosts / groups / containers.
- **🔷** Nesting stays: group → host → LXC child, not a flat “open sessions” list.
- **🔷** If **nothing** is open, show the full tree (today Localhost almost always has a tab, so this is rare).
- **🔷** A **toggle button at the bottom** (with search) switches open-only / all.

### Landed

- **ℹ️** `Host.Tree`: `Gtk.CustomFilter` + `Gtk.FilterListModel` on roots and on each children list.
- **ℹ️** `Connection.children_open` count; session 0↔1 walks ``parent`` and increments/decrements.
- **ℹ️** `TreeNodes.num_open` is how many connections have a tab; 0 → show the full tree.
- **ℹ️** `Host.Tree.show_all` bound to a `Gtk.ToggleButton` next to the search entry.
- **ℹ️** `TreeNodes.open_changed` when a row’s `sessions` change or a row is appended, so the filter refreshes.

## Phase 2 — Empty-space hint; revert to open-only

- **🔷** `✔️` Empty tree space is a hint: click → all hosts (same as the Phase 1 toggle).
- **🔷** `✔️` Open or select a host → revert to open-only.

### Behaviour

- **🔷** `✔️` Leftover **whitespace** under the open rows is a hint: click → show **all** hosts.
- **🔷** `✔️` Hint chrome: **light grey background text** in that unused area (normal placeholder trick).
- **🔷** `✔️` Click empty tree space: same as toggling to **all**.
- **🔷** `✔️` Open or **select** a host from that all-hosts tree → **revert** to open-only.
- **💩** Exact hint wording — landed as “Click to show” / “all hosts”.

### Landed

- **ℹ️** `Gtk.Overlay` on the list: dim `open-hint` label, bottom of the pane, hidden when `show_all` or `num_open == 0`.
- **ℹ️** Primary click on list whitespace sets `show_all` (toggle stays in sync).
- **ℹ️** Select reverts only if that row is already open or a parent of an open row (a closed host must stay visible so double-click can open it).
- **ℹ️** Open reverts when `num_open` increases (after the session exists, so SSH does not hide the row first).
- **ℹ️** Clicking a session mark also sets `show_all = false`.

## Phase 3 — Search filters the tree

- **🔷** `✔️` Search filters the tree by name; a row is visible if it or a child matches.
- **🔷** `✔️` Delete the pulldown / popover. The tree is the result list.

### Today (before this phase)

- **ℹ️** `Host.SearchPulldown` — entry + **popover** over the **flat** openable list (`TreeNodes.flat`). Does not filter the tree.
- **ℹ️** Wishlist already asked to change search into a **filter**.

### Behaviour

- **🔷** `✔️` Search is a **tree filter by name**.
- **🔷** `✔️` Delete the search **pulldown / popover**.
- **🔷** `✔️` Starting to type: **open-only off**; match names in the nest; hide non-matches.
- **🔷** `✔️` A matched row still shows its **parents** (group / host leading to an LXC hit, etc.).
- **🔷** `✔️` Visibility for any tree row: **own name matches**, **or** a **child matches**. Same shape as Phase 1 (open **or** a child is open).
- **🔷** `✔️` `key-search` (Ctrl+Shift+O) still focuses that search entry (unchanged).
- **🔷** `✔️` Open or **select** a host from a name search → **revert** to open-only; clear the search.
- **ℹ️** Select reverts only if that row is already open or a parent of an open row (same as Phase 2: a closed host must stay visible so double-click can open it).

### Landed

- **ℹ️** Search is a `Gtk.SearchEntry` on `MainWindow` (clear button; no pulldown).
- **ℹ️** `Tree.search` bound to the entry; non-empty search sets `show_all` and uses name match.
- **ℹ️** `Tree.search_uuids`: match uuids plus parent uuids; filter is membership in that set.
- **ℹ️** After a name search, expand rows in that set so the hit is visible under its parents.
- **ℹ️** Open, select of an already-open row, session-mark click, or turning the all-hosts toggle off clears the search.

## Phase 4 — LXC tabs on the parent host page

- **🔷** `✔️` Opening an LXC container adds a tab on the parent host’s page.

### Today

- **ℹ️** Local path tabs already live on the **Localhost** page (`Session.Controller.open_local` uses `parent` as the page owner).
- **ℹ️** SSH / LXC `create()` keys the `Gtk.Stack` page by **that connection’s uuid** — each LXC container gets its **own** `Host.Page`.

### Behaviour

- **🔷** `✔️` Opening an LXC container adds a **tab on the parent host’s page**, like local paths on Localhost.
- **🔷** `✔️` Several containers on one machine share that host’s tab strip.
- **🔷** `✔️` Same `page_connection = parent` pattern as `open_local` when `kind == LXC`.
- **🔷** `✔️` A plain SSH tab on that host stays on the same page.
- **🔷** `✔️` Any SSH into that host (plain SSH and LXC children) is **grouped together** on that host’s page.
- **🔷** `✔️` Tree highlight is the **selected row** (the LXC row if that is what is selected, not the parent host row).
- **🔷** `✔️` Showing that tab still uses the **host** page (`get_child_by_name` on the parent), then selects that tab.

### Landed

- **ℹ️** `Session.Controller.create`: LXC uses `page_connection = parent` (same shape as `open_local` for local paths).
- **ℹ️** `Host.Page.add` / close: sessions stay on `term.connection` (LXC row), not the page owner.
- **ℹ️** `MainWindow` page lookup: LXC and local paths use the parent uuid; tab select uses the terminal from that row’s `sessions` (not tab-strip index).
- **ℹ️** Tree highlight follows `page.current.connection` (the LXC row when that tab is selected).

## Phase 5 — Expand / collapse (park persist)

- **🔷** `⏳` Stop expand persist; unfiltered all expanded; filtered expand to open / match paths.
- **🔷** `⏳` Tab change expands so the selected row is visible.

### Today

- **ℹ️** 0.14 persist: `Connection.expanded` in JSON; restore on `TreeListModel` before ListView (`docs/plans/done/0.14-DONE-tree-expand-save-restore.md`).

### Behaviour

- **🔷** Disable **save/restore** of expand for the time being.
- **🔷** Unfiltered (show all, empty search): every group / LXC host / Localhost **expanded**.
- **🔷** Filtered: expand a row when it has an **open** child (Phase 1) or a **name-matching** child (Phase 3) — so the hit is actually visible under its parents.
- **🔷** You **may collapse** a row in the all-hosts view if you like.
- **🔷** Change tab → expand again so the **visible** connection’s row can be seen (at least that path).

### After approval

- **ℹ️** Touch: expand bind / `notify["expanded"]` save.
- **ℹ️** Stop writing expand on toggle while persist is parked. `Connection.expanded` can linger unused on the object / JSON until persist comes back.
