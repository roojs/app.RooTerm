**Status:** ⏳ proposed (design; no code until review)

**ℹ️** Next number after **0.18** fullscreen.

---

## Purpose

- **🔷** Reorganise **finding and opening** hosts: working view vs hunting for a new host.
- **🔷** While working you mostly want **currently open** rows, not the full available tree.
- **🔷** Open rows stay **in tree context**: an open LXC container still shows the parent host (and groups) that lead to it; hide everything else.
- **🔷** Default: if anything is open, the tree shows **only** that open set (plus those ancestors).
- **🔷** Hunting a new host is frequent → **search**.
- **🔷** Turn today’s search into **search + toggle**.
- **🔷** Typing a search **turns the open-only filter off** and filters the **tree by name**.
- **🔷** Empty space in the open-only tree is a **hint**: click it to show **all** hosts (same as the toggle).
- **🔷** A **toggle button at the bottom** (with search) also switches open-only / all.
- **🔷** Opening a host from the **all-hosts** tree **reverts** to open-only.
- **🔷** LXC container tabs sit on the **host machine’s page** (grouped with that host), not a page per container.
- **⏳** Design review, then implementation fences.

---

## Current behaviour

- **ℹ️** Left pane: full nested `Host.Tree` (`connections.json`).
- **ℹ️** Search under the tree: `Host.SearchPulldown` — entry + **popover** over the **flat** openable list (`TreeNodes.flat`). Does not filter the tree.
- **ℹ️** Wishlist already asked to change search into a **filter** and to think about opened vs full list.
- **ℹ️** Local path tabs already live on the **Localhost** page (`Session.Controller.open_local` uses `parent` as the page owner).
- **ℹ️** SSH / LXC `create()` keys the `Gtk.Stack` page by **that connection’s uuid** — each LXC container gets its **own** `Host.Page`.

---

## Proposed behaviour

### Open-only tree (default when anything is open)

- **🔷** Show a row if it is **open**, or it is an **ancestor** of an open row.
- **🔷** Hide all other hosts / groups / containers.
- **🔷** Nesting stays: group → host → LXC child, not a flat “open sessions” list.
- **🔷** Leftover **whitespace** under the open rows is a hint: click → show **all** hosts.
- **💩** “Open” = that connection has at least one tab (`sessions` non-empty). Ancestors need not have their own tab.
- **💩** If **nothing** is open, show the full tree (today Localhost almost always has a tab, so this is rare).
- **💩** Hint chrome (dim label / pointer) — not specified; click target is the unused tree area.

### Search + toggle

- **🔷** Search is a **tree filter by name**, not (only) a pulldown of a flat list.
- **🔷** Starting to type: **open-only off**; match names in the nest; hide non-matches.
- **🔷** Toggle **at the bottom** (with the search row): open-only vs all hosts.
- **🔷** Click empty tree space: same as toggling to **all**.
- **🔷** Open a host from that all-hosts tree → **revert** to open-only (the new host now in the working set).
- **💩** Keep `key-search` (Ctrl+Shift+O) as focus on that entry.
- **💩** Name match also keeps **ancestors** of hits (same “in context” rule as open-only).
- **💩** Open from a **name search** also reverts to open-only (search cleared).
- **💩** Drop the search **popover** once the tree itself is the result list.

### LXC tabs on the host page

- **🔷** Opening an LXC container adds a **tab on the parent host’s page**, like local paths on Localhost.
- **🔷** Several containers on one machine share that host’s tab strip.
- **💩** Same `page_connection = parent` pattern as `open_local` when `kind == LXC`.
- **💩** A plain SSH tab on that host stays on the same page.
- **💩** Tree highlight / `get_child_by_name` for an LXC row must use the **host** page, then select that tab.

---

## Suggested order

1. **🔷** `⏳` Open-only tree (ancestors of open rows; hide the rest).
2. **🔷** `⏳` Empty tree space + bottom toggle → all hosts; open a host → revert to open-only.
3. **🔷** `⏳` Search filters the tree by name; typing turns open-only off.
4. **🔷** `⏳` LXC tabs on the parent host page.
