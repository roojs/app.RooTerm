## Purpose

- **🔷** Tree session icons show **state** (active / idle / busy / finished / dead), not only opacity.
- **🔷** Background SSH exit: **hold** with a red mark; do not auto-close after 10s until the user has looked.
- **🔷** After the user focuses a dead session: bottom **draining countdown** (~30s) with **Pause / Keep open**; **Enter** reconnects.
- **🔷** Host **tab bar always visible** (even for one tab).
- **🔷** Tab bar **right**: pulldown of **previous sessions** (last prompt + date/time) → open read-only history view.
- **🔷** In-memory **500-line** live VTE rotating log; flush with typed input under `~/.local/share/rooterm/sessions/<uuid>/YYYY/MM/`.
- **🔷** Also keep the **command / input** log (same session stamp, sibling file).
- **🔷** Optional post-login **sudo**, **LXC console**, and **SSH key setup** (password → key); LXC hosts can grow **container children** in the tree.
- **🔷** **Local shells** on the left tree (localhost — not a saved/configurable host).
- **🔷** **Guake**-style overlay for local terminals (toggle, semi-transparent; restore last locals later).

## Session icon states (tree marks)

Per open tab icon on the host row (today: `video-display` + opacity).

| State | Look | Meaning |
| ----- | ---- | ------- |
| **Active** | Current emphasis (full colour / existing active style) | Focused tab for that host |
| **Idle** | **Grey** muted icon | Background; no interesting activity since leave |
| **Busy** | **Grey spinner** only (same quiet family as idle) | Output still arriving while unfocused — slightly more interesting than idle, not attention-seeking |
| **Ready** | **Solid / dark blue** icon | Activity finished since leave; unread output waiting |
| **Dead** | **Red** icon | Child exited while in background (or unfocused) |

- **🔷** Busy is **not** blue and **not** a pulse — just a quiet grey spinner (idle-adjacent).
- **🔷** Focused tab stays **active** styling; busy/ready/dead apply when **not** the focused session (or not the focused host page — confirm: tree mark vs tab chrome).
- **💩** Also tint **Adw tab** titles the same way — confirm if wanted in this plan or later.
- **ℹ️** Detection sketch:
  - leave focus → idle
  - VTE output while unfocused → busy
  - quiet for a short settle window → ready
  - `child_exited` while unfocused → dead
  - user focuses → clear ready/busy; dead stays until reconnect or close

## Background exit / reconnect

Today: `SshTerminal` exits → 10s delay → close tab always.

- **🔷** If the tab is **unfocused** (background): set state **dead**, **do not** start the 10s close timer.
- **🔷** When the user **focuses** that tab: show the exit banner; start a **~30s** close countdown if they do nothing.
- **🔷** **Countdown chrome** at the **bottom** of the terminal: horizontal bar that **drains backwards** (progress emptying), label like **“Closing in 30 seconds…”** (tick down).
- **🔷** **Pause / Keep open** on that bar — stops the countdown and leaves the dead session open until the user reconnects (Enter) or closes the tab themselves.
- **🔷** **Enter** on a dead session → **reconnect** in the same tab (re-`spawn` / new SSH), clear dead state and hide the bar.
- **🔷** If focused when exit happens: same countdown bar + pause (retire the silent 10s close).
- **🔷** Applies to **SSH / remote** sessions — **not** local shells (see Local shells).
- **🚫** Silent discard of background failures.
- **🚫** Auto-close with no visible countdown once the user has looked.
- **🚫** 30s draining close timer on **local** PTYs.

## Logging / buffers

Not config, not cache — **XDG data**: `~/.local/share/rooterm/sessions/`.

Layout:

```
~/.local/share/rooterm/sessions/<uuid>/index.json
~/.local/share/rooterm/sessions/<uuid>/<YYYY>/<MM>/<stamp>-input.log
~/.local/share/rooterm/sessions/<uuid>/<YYYY>/<MM>/<stamp>-vte.log
```

- **🔷** Per connection **`uuid`**: `index.json` lists past sessions (prompt + datetime + relative paths) for the pulldown.
- **🔷** Files under **`YYYY/MM/`** only (no day dir — a month’s files in one folder is fine).
- **🔷** Two files per stopped session:
  1. **`…-input.log`** — what was typed (commands; redacted secrets)
  2. **`…-vte.log`** — flush of the live **500-line** VTE rotating log (cmd + output)

Live behaviour:

1. **🔷** **Input stream** — append typed lines as today (but write under the path above, not Ásbrú `session_logs`).
2. **🔷** **VTE rotating log** — in-memory 500-line ring from VTE; on stop flush to `…-vte.log` and update `index.json`.
3. **🔷** Opening history from the pulldown → feed `…-vte.log` into a read-only VTE.

- **🔷** Losing the in-memory ring on crash is acceptable; flush on orderly stop / dead / user close.
- **🚫** Store session dumps under `~/.config` or `~/.cache`.
- **🚫** Do not grow unbounded in-memory history.
- **🚫** Separate “output log” format parallel to VTE — the rotating log *is* the VTE feed text.
- **ℹ️** `~/.local/state` was considered; **share** wins so history is clearly user data, not disposable state.

## Sudo + LXC + SSH key setup

### Post-login actions (connection options)

- **🔷** Flag / option: **sudo after login**
  - after first shell prompt: send **`sudo -i`**
  - wait for sudo password prompt → feed same connection password from libsecret (once)
  - then wait for root prompt
- **🔷** Flag / option: **LXC console** with container name
  - after (optional sudo) prompt: send `lxc-console -n <name>` (user said `lxc console -a` — **confirm** exact binary/flags: `lxc-console` vs `lxc console`)
- **🔷** These are **per connection** settings in `ConnDialog` / JSON (not Expect scripts).
- **🚫** Full Ásbrú Expect list import.

### SSH key setup (password → key)

For connections that still use **user/password** auth, offer **Set up SSH key login** (ConnDialog) when a local identity exists, or create one via **`KeyDialog`**.

- **🔷** Run the setup in a **visible terminal** (VTE) so the user can watch / intervene — not a silent background process.
- **🔷** Prefer **`ssh-copy-id -p <port> -i <key.pub> user@host`** — OpenSSH’s script **does** support **`-p`** for non-22 ports.
- **🔷** Feed the connection password when `ssh-copy-id` / ssh prompts (same libsecret secret).
- **🔷** **Inspect** the terminal output for success / failure (e.g. “Number of key(s) added” vs permission denied / host key errors) before mutating config.
- **🔷** On success: set **`auth` to `ssh_key`**, set **`public_key`** to the identity used, **`Config.save()`**; keep the dialog password until Save/close (so sudo can be enabled without retyping).
- **🔷** New keys are **passphrased** (enter twice in **`KeyDialog`**); passphrase in **libsecret** keyed by identity path.
- **🔷** **Replace** an unprotected key (not in-place “upgrade”): create a **new** passphrased identity → install on the server → **separate** step removes the old pubkey from ``authorized_keys`` after the user verifies the new key works (`Connection.retire_key`).
- **🔷** On Save (and edit UI): if the identity has **no passphrase**, tell the user and offer **Replace key…**.
- **🔷** Failed **sudo** password (prompt returns / “Sorry, try again”) → alert with **Edit**.
- **💩** If `ssh-copy-id` is missing or fails on an odd host: fallback via **`scp -P <port>`** / append to `authorized_keys` in a visible terminal — only if copy-id proves insufficient.
- **🚫** Auto-convert every password host on import; **🚫** remove password without a successful key install.
- **🚫** Create new identities **without** a passphrase as the default path.
- **🚫** Delete the old **local** private key as part of replace (retire on the **server** only).
- **🚫** Remove the old server pubkey in the same step as install — verify first.

### Container children in the tree

- **🔷** An SSH host can have **child rows** that are LXC containers (not separate SSH hosts).
- **🔷** Double-click a container child → open session that SSHs to the parent host then runs **`lxc-console -n <name>`** by default (or **`lxc-attach -n <name>`** when that is the saved default).
- **🔷** **Discover**: connect and run **`lxc-ls -f -F name,state`** (fancy, two columns) → parse `NAME`/`STATE` rows → create/update child rows.
  - **ℹ️** Plain `lxc-ls` on a TTY is space-separated on one line — **not** parse-friendly.
  - **ℹ️** **`lxc-ls -1`** = one name per line (also machine-friendly if we only need names).
  - **ℹ️** **`-f` / `-F`** = column output; use for name + running/stopped.
- **🔷** Tree context menu on an LXC-capable host: **Refresh containers**.
- **🔷** Tree context menu on a **container** row: **console** / **attach** defaults — see **0.4**.
- **🔷** ConnDialog **LXC host** + **Fetch hosts** for discover.
- **ℹ️** Children stored in RooTerm JSON (`lxc_container`, `lxc_name`, `parent_uuid` = host).

## Local shells (localhost in the left tree)

General feature for the **main window** (and reused by Guake) — not Guake-only.

- **🔷** Built-in **Localhost** (or “Local”) entry in the left tree — **not** a user-editable connection in `ConnDialog` / JSON.
- **🔷** Open local PTYs show as an **expanded tree** under that entry, labelled by **cwd/path** (not only flat session icons on a fake host row).
- **🔷** Same session mark states (active / idle / busy / ready / dead) apply to local shells.
- **🔷** **Ctrl+Shift+N**: new local terminal into **home** (default); optional later: inherit cwd of the focused local tab.
- **🔷** Double-click Localhost (or an empty area under it) / shortcut opens a new shell; selecting a path child focuses that shell.
- **🔷** **No tab bar** on Localhost — the path tree is the switcher (SSH hosts keep the tab bar).
- **🔷** **Ctrl+D**: exit / close the **current local shell** (tear down that PTY; drop it from the path tree).
- **🔷** Local sessions reuse history / VTE log machinery where it fits (uuid for localhost is a fixed synthetic id).
- **🔷** Local shell exit is **immediate** — no dead-hold, no red mark countdown, no 30s bar (unlike SSH).
- **🚫** ConnDialog for localhost; **🚫** storing local shells as configurable hosts in `connections.json`.
- **🚫** Apply Phase 12 close countdown to local shells.

## Class / file list (named for implementers)

Short names; approve before adding methods beyond these entry points.

- **`SessionState`** - enum or string states for marks (`idle` / `busy` / `ready` / `dead` / active implied by focus).
- **`SshStream`** - VTE `on_commit` / `on_prompt` / `on_password` / `on_log` only (connected in constructor); post-login sudo / LXC steps add more `on_*` here.
- **`SshTerminal`** - chrome, spawn/reconnect, dead hold; creates {@link SshStream} after the VTE exists.
- **`Terminal`** - shared VTE tab base for {@link SshTerminal} / {@link LocalTerminal}.
- **`HostTree`** - superseded by **0.4** (`HostTreeView` / `HostTreeNodes`); localhost path tree later still applies on the view.
- **`HostPage`** - always-on tab bar; history pulldown; wire reconnect.
- **`SessionHistory`** - `~/.local/share/rooterm/sessions/<uuid>/` index + `YYYY/MM` input/vte files.
- **`LocalTerminal`** - local PTY sibling of `SshTerminal` (main window + Guake).
- **`GuakeOverlay`** - borderless overlay chrome; left path tree + bottom search; bottom tabs with ×/`+`; D-Bus `show_hide` / quit; height resize; reuses localhost sessions.
- **`Application`** - extend OLLMchat-style `OptionEntry` / `command_line`: `--toggle`, `--toggle-key`, `--quit` (beside existing `--debug`).
- **`extension/`** (or `gnome-shell-extension/`) - thin Shell extension: D-Bus client + `addKeybinding` (default F12) + panel Toggle/Quit; hover tooltip (gitlive). Borrow **whisrs** + **gitlive**.
- **`Connection`** - fields: `sudo_after_login`, `lxc_container` / `lxc_name`, `lxc_enter` (`console`|`attach`), maybe `kind` (`ssh` | `lxc`).
- **`ConnDialog`** - toggles for sudo / LXC; **Set up SSH key** when password auth; container name when relevant (**not** localhost).
- **`MainWindow`** - top bar **Add group** (with add host).
- **`Config`** - persist new connection fields (not local shell rows).

### Phase 15a — Guake overlay chrome

Builds on Local shells — same localhost PTYs, different chrome. Local only; SSH stays in the main window.

**Scope:** UI only. In-app toggle (**F12** default) hide/show **only while RooTerm already has focus**. Global toggle is **15b** (D-Bus + Shell extension — one phase; both required).

```
┌─ left: localhost path ColumnView ─┬─ right: VTE ────────── scrollbar ┐
│  path rows                        │  terminal                         │
│  …                                │                                   │
├─ search (leftmost under tree) ────┼─ tabs [path ×] … ── [+] ──────────┤
└───────────────────────────────────┴───────────────────────────────────┘
```

- **🔷** `⏳` Borderless semi-transparent overlay under the top panel — **no** titlebar / close / window decorations.
- **🔷** `⏳` Layout: left = localhost path `ColumnView`; right = VTE + scrollbar; **search** under the ColumnView (left pane footer); **tabs at bottom** of the right pane.
- **🔷** `⏳` Each tab: label = **path only** (no hostname); **×** close (same tear-down as Ctrl+Shift+W / Ctrl+D — drop PTY from path tree).
- **🔷** `⏳` Many tabs: **cramp / shrink** — ellipsis truncated labels; **tooltip = full path**. **🚫** Guake left/right tab scroll buttons.
- **🔷** `⏳` Tab strip **`+`**: new local shell (tooltip **Ctrl+Shift+T**).
- **🚫** Guake’s right-hand “pick a tab” combo — left path tree is the switcher.
- **🔷** `⏳` Reuse the same localhost sessions as the main-window Localhost tree.
- **🔷** `⏳` In-app toggle when overlay/app focused (**F12** default) — hide/show only (does not quit). **Does not** work when another app is focused — that is **15b**.
- **🔷** `⏳` Fixed default height / opacity (full width); **no** prefs UI; **🚫** draggable resize here (→ **15b** greenfield pass).
- **🔷** `⏳` Core accelerators:

| Action | Default |
| ------ | ------- |
| Toggle overlay | **F12** (in-app / focused only; Guake-like — **F1** conflicts with Help elsewhere) |
| New local terminal | **Ctrl+Shift+T** (+ button) |

### Phase 15b — D-Bus + Shell extension (+ geometry) — greenfield

**Do together** — D-Bus, Shell extension, and overlay geometry are all greenfield (new `GuakeOverlay` / `extension/` / Application CLI flags). Very little touch of existing host/SSH code. Land as one milestone after **15a** chrome exists.

Patterns:

- **whisrs** (`/home/alan/git/whisrs/contrib/gnome-shell-extension`): session-bus Control; `Main.wm.addKeybinding` → D-Bus; panel menu; X11 + Wayland.

```
toggle key / panel  →  Shell extension  →  D-Bus  →  RooTerm GuakeOverlay
rooterm --toggle / --toggle-key / --quit  →  same D-Bus (or local OptionEntry handlers)
```

**RooTerm (D-Bus + CLI):**

- **🔷** `⏳` Session-bus API: **`show_hide`**, **`quit`**.
