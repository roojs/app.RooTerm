## UI shape (v1)

```
Adw.PreferencesDialog
 └── Adw.PreferencesPage
      ├── PreferencesGroup "Keyboard"
      │    └── ActionRow "Toggle key"     → entry / accelerator widget (suffix)
      └── PreferencesGroup "Appearance"
           ├── ActionRow "Opacity"        → spin / scale (suffix)
           ├── ActionRow "Height"         → spin % (suffix)
           ├── ActionRow "Width"          → spin % (suffix)
           └── ActionRow "Placement"      → dropdown left | centre | right (suffix)
```

- **🔷** Full-width rows: title (and optional subtitle) on the left; control as **suffix** — same Adwaita / OLLMchat Connections-style key–value rows (`ActionRow` + `add_suffix`), not a custom form grid.
- **🔷** Single page only — no tabs, no ViewSwitcher.
- **💩** Present from menu / gear / header action on {@link MainWindow}; exact trigger TBD.
- **ℹ️** Pattern reference: OLLMchat `SettingsDialog/ConnectionAdd.vala` (`PreferencesDialog` + `PreferencesGroup` + `ActionRow`); row widgets like `Rows/String.vala` / `Rows/Int.vala` for suffix controls — **do not** copy the multi-tab `MainDialog`.
- **🚫** New Row helper class forest unless the user asks — inline `ActionRow` + control in the dialog is fine for five fields.
