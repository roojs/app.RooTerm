## Purpose

- **🔷** Persist open local tabs as `LOCAL_PATH` rows in `connections.json`.
- **🔷** Absolute path on serialized `Connection.cwd` (not in `name`).
- **🔷** `name` stays the tree / tab label (`~/…`, `root:…`).
- **🔷** Save on open, close, and when `cwd` changes (not while elevated).
- **🔷** On startup, reopen each saved `cwd` that still exists; skip / drop missing paths.
- **🔷** Cannot restore root — freeze `connection.cwd` once `peer_user` is elevated.
- **🔷** `Config.save` warns on failure and does not throw.

---

## Behaviour (shipped)

- **✔️** `LOCAL_PATH` registered in `by_uuid` with `cwd` + label `name`.
- **✔️** Open / close / cwd change → `config.save()`; elevated shells do not update `cwd`.
- **✔️** `Config.load` leaves `LOCAL_PATH` in `by_uuid` only (no tree-attach; parent Localhost not in JSON yet at load).
- **✔️** Startup: unset saved path rows, `open_local` for each existing `cwd`; home tab only if none restored; then `save`.
