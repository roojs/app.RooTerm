---

## Purpose

- **🔷** Full-screen terminal mode (not just a prefs accel with no behaviour).
- **🔷** Control: icon to the **right of the ``+``** on the tab strip.
- **🔷** In full screen the same control shows a **half-screen / restore** icon (exit).
- **🔷** In full screen: **tabs + that chrome at the top** (not bottom).
- **🔷** Animate the transition (quick — see **Animation**).
- **🔷** Persist full-screen **for the session** (hide/show) until the user exits — **not** in ``config.json`` / not across app restart.
- **🔷** Shortcut + VTE context-menu entry (``key-fullscreen``).

---

## Layout

- **🔷** Full screen: tab strip above the VTE; exit → strip on bottom.
- **🔷** Steady state: **one** ``Host.TabBar`` (reparented between ``chrome_top`` / ``chrome_bottom``).
- **🔷** **Keep** host tree + search in full screen.
- **🔷** ``Host.Page``: ``chrome_top`` → ``tab_view`` → ``chrome_bottom``; only the bar moves.
- **💩** Hide bottom ``drop-shadow`` while full screen? Left open.

### Icon

- **🔷** Space right of ``+`` always; ``view-fullscreen-symbolic`` / ``view-restore-symbolic``; ``win.fullscreen``.

---

## Window / Shell geometry

- **🔷** Fill monitor **work area** under the Shell top bar (not compositor fullscreen over the panel).
- **🔷** ``redock(fullscreen)``; Shell sizes ``main``; undecorated; one ``main`` role.
- **🚫** GTK ``fullscreen()`` over the panel; second Meta window.
- **🔷** **F12** while full screen: exit FS then normal hide.
- **🔷** Hide/show while still FS this session: restore work-area FS until user exits.

---

## Animation

**🔷** Ship: Shell interpolates ``move_resize_frame`` (~320 ms, same as pull-down). Tab chrome flips **after** the ease.

### Enter / leave

- **🔷** ``redock(fullscreen)`` → ease frame to work area / dock % (monitor geometry for %).
- **🔷** After ~320 ms: ``Host.Stack.fullscreen``; GTK ``set_default_size`` aligns.

### Rejected

- **🚫** Tab-bar translucent fade/slide.
- **🚫** Actor scale-after-resize.
- **🚫** Flip chrome before the ease (kept **after**).
- **🚫** Black spacer morph / dual live tab bars.

- **🔷** Session-only state (``MainWindow`` / D-Bus); not ``config.json``.
