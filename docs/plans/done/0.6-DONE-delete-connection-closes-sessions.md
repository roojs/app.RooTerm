## Purpose

- **🔷** ✔️ Confirmed delete of a connection must **kill** its open sessions and **close their tabs immediately**.
- **🔷** ✔️ No 30s countdown, no focus-then-countdown chain — delete is already confirmed and destructive.
- **🔷** ✔️ Wire delete in {@link Host.TreeMenu}: `Posix.kill` each live `child_pid`, then `close_in(0)` on each session.
- **🚫** Rely on EXITED hold / `close_in(30)` for delete.
- **🚫** `set_pty(null)` in the delete handler.
- **🚫** New helper methods (`kill_child`, `exit_sessions`, …) — inline only.
- **💩** Group delete (empty of children) — no sessions; no extra work.
- **ℹ️** Normal SSH death still uses EXITED + 30s when focused — unchanged by this plan.
- **ℹ️** Reconnect-after-exit skipping login is a **bug**, not this plan — `docs/bugs/2026-07-30-reconnect-skips-open-session-login.md`.

---

## Current behaviour (before)

- **ℹ️** Delete (`Host.TreeMenu`): `conn.deleted = true`, tree remove, save — **sessions left running**.
- **ℹ️** {@link Terminal.Base.child_pid} set on successful SSH / local spawn; cleared on spawn failure / local exit.
- **ℹ️** `close_in(0)` closes the tab immediately (`close_confirmed` + `close_tab`).

---

## Behaviour

- **🔷** ✔️ On confirmed delete of a host / LXC (anything with open `conn.sessions`):
  - `Posix.kill` each session’s `child_pid` (SIGTERM) when `> 0`
  - `close_in(0)` on **every** session (visible or not) — tabs gone at once
- **💩** Group delete — no sessions; no extra work.

## 2. Delete kills and closes sessions now

### 2.1 `src/Host/TreeMenu.vala` — delete confirm kills pids + `close_in(0)`

**Why:** User already confirmed delete — tear down every open session immediately; do not leave EXITED tabs or a 30s chain.

**Where:** `alert.response` success path, after `tree.remove(conn)`, before `config.save()`.

**Depends on:** §1 (already done).

**ℹ️** Loop is **reverse** index — `close_in(0)` removes from `sessions` synchronously via `close_tab` / `close_page`; forward would skip.

#### Applied

```vala
					conn.deleted = true;
					this.window.config.tree.remove(conn);
					// reverse: close_in(0) removes from sessions synchronously
					for (var i = (int) conn.sessions.get_n_items() - 1; i >= 0; i--) {
						var term = (Terminal.Base) conn.sessions.get_item(i);
						if (term.child_pid > 0) {
							Posix.kill(term.child_pid, Posix.Signal.TERM);
						}
						term.close_in(0);
					}
					try {
						this.window.config.save();
					} catch (GLib.Error e) {
						GLib.warning("config save failed: %s", e.message);
					}
```
