# 0.23 — Script sender and sqlite tree

**Status:** DONE (user closed 2026-11-18). The tab strip is the machine switcher. Per-row status words and keeping login dialogs off the main window were left out.

**Pointer:** `docs/guide-to-writing-plans.md` — **Checklist for plans**; Vala via **`docs/coding-standards-router.md`**. Build: **`docs/build-rules.md`**.

**ℹ️** Next number after **0.22** search cursor (`docs/plans/done/0.22-DONE-search-result-cursor.md`).

**ℹ️** Script and task shape follows Argus `shared/SQT/Script.vala` and `shared/SQT/Task.vala`. The tick grid follows `argusrm/controller/dialog/Upgrade.vala`. Storage is `SQ.Database` / `SQ.Query` from libocsqlite (`OLLMchat/libocsqlite`).

Code fences for these new files land after this shape is agreed. This document is the behaviour and the schema.

---

## Purpose

- **🔷** A **Script sender** window lists scripts and creates them in a form dialog.
- **🔷** **Execute** picks servers with the Argus tick grid, then creates a **task**.
- **🔷** The task runs in a **batch** window.
- **🔷** That window has two views: **Planning** and **Running**.
- **🔷** Running starts one terminal per ticked machine and uses the RooTerm login flow.
- **🔷** Those terminals live in the batch window. You can switch which one you are looking at.
- **🔷** Running shows progress: each command has run and completed.
- **🔷** When the run is finished, one close dismisses that batch and every terminal in it.
- **🔷** A batch against an LXC container uses `lxc-attach`, not `lxc-console`.
- **🔷** The host **tree** moves into a sqlite database through **ocsqlite**.
- **🔷** Script, task, and the related tables keep the **full Argus columns**, so this database can grow into that model later.
- **🔷** Row classes live in `src/SQT/`. Later UI follows Argus: `src/tab/`, `src/dialog/`, `src/store/`.
- **ℹ️** Phases 1–4 are in the tree. Feeding the script body is `Jobs.Batch.inject`.

---

## Current behaviour

- **ℹ️** The tree is `~/.config/rooterm/connections.json`. `Host.TreeNodes.load` / `save` read and write the whole nest. `ConfigMigrate` still folds an old combined file into that JSON.
- **ℹ️** `Host.Connection` is the live row and the JSON document. Passwords and passphrases are libsecret, keyed by `uuid` (LXC uses the parent uuid). They are not in the file.
- **ℹ️** `kind` is a JSON integer. Enum order is permanent (`HOST`, `GROUP`, `LOCAL`, `LOCAL_PATH`, `LXC`).
- **ℹ️** Sibling order is array order. Parent link is `parent_uuid`. Forwards are a nested array on the connection.
- **ℹ️** `expanded` is in the JSON. Saving it on toggle is parked (`docs/plans/done/0.14-DONE-tree-expand-save-restore.md`).
- **ℹ️** An interactive LXC session is `Jobs.OpenSession`: spawn, `login`, optional `sudo -i`, then `lxc-console -n NAME`.
- **ℹ️** `Jobs.Job` builds its terminal through `Session.Controller.create`, so the tab lands on the main window.
- **ℹ️** Chrome (`config.json`: theme, font, workspace last tab) is separate from the tree.
- **ℹ️** Shell owns `main` and `preferences` only. The connection editor is an ordinary GTK window.

---

## Proposed behaviour

- **🔷** One database file: `~/.config/rooterm/rooterm.db`.
- **🔷** Open it with `SQ.Database`. Rows go through `SQ.Query`.
- **🔷** `config.json` stays the chrome file. Libsecret stays the password store. `uuid` stays the secret key.
- **🔷** First launch that finds `connections.json` and an empty database loads that JSON, inserts the rows, and renames the file to `connections.json.migrated`.
- **🔷** After that, the tree loads and saves through sqlite. A later `connections.json` is not read again.
- **🔷** The database file stays open. There is no whole-tree save. An edit inserts, updates, or deletes that one row.
- **🔷** Script sender and each batch are ordinary GTK windows, like the connection editor. They are not new Shell roles.
- **🔷** Script sender stays open while a batch runs. Closing a batch does not close the sender.
- **🔷** A batch terminal is not a main-window tab. `Session.Controller.create` is not used for it.
- **🔷** Interactive **Open** on an LXC row still uses `lxc-console`. Only a batch uses `lxc-attach`.

- **🔷** `✔️` `src/SQT/` holds the row classes. `SQT.init_db` creates every table below, including the Argus ones, on open.

## Phase 2 — Script sender

- **🔷** `✔️` The `script` table from Phase 1. The form edits `path` (the nickname) and `body`. Other Argus columns stay on the row at their defaults.
- **🔷** `✔️` Window title **Script sender**. Close on the left, **Add command** on the right. Search is a row under the header. Opened from the terminal right-click menu.
- **🔷** `✔️` The list is a `src/store/` over `SQT.Script`. Columns are nickname, command, and a play button. A row opens the form. **Add command** opens it empty.
- **🔷** `✔️` Save inserts or updates the row and refreshes the list.
- **🔷** **Test** on the form saves first. A valid save leaves the form open and opens Planning, so the command can be tried on one or many hosts. An empty nickname or an invalid success criteria does not open Planning.
- **💩** `✔️` Delete on the form, with a confirm. A script that a task still points at stays in the database.
- **🔷** `✔️` Optional one-line **Success criteria** under the command, with that label above it. The line under the label says use this to validate completion or success, and that a command can end with `&& echo "SUCCEEDED"` so the check is `SUCCEEDED`. Empty is allowed. Save rejects a pattern that is not a valid regular expression. Not an Argus column: `script.success_regex` text.

## Phase 3 — Planning

- **🔷** `✔️` **Execute** on a script opens a batch window on **Planning** and inserts a `task`. `script_id` is the library row. `is_draft` stays 1 while planning.
- **🔷** `✔️` The window keeps that script. `path`, `body`, and `success_regex` are not copied onto the task or the job.
- **🔷** `✔️` A tick inserts a `task_target` (`agent_id` holds `connection.id` until a real agent id exists). Clearing it removes that target. This is only while `is_draft` is 1.
- **🔷** `✔️` **Run** needs at least one target. It sets `is_draft` to 0 and switches the window to **Running**.
- **💩** `✔️` How far through the body a machine got is stored in `task_target.identifier`, so the Argus table stays unchanged.
- **🔷** `✔️` Planning is the host tree, with the same collapse as the main window.
  - A check column on hosts and LXC containers.
  - Search, and **Hosts** / **Hosts + containers** / **Containers** beside **Select all**.
  - **Select all** / **Select none** for the rows the filter is showing.
- **🔷** `✔️` Groups stay in the tree and are not ticked. Local paths are not listed.
- **💩** `✔️` Localhost is not in the list. This is servers.
- **💩** `✔️` You can open more than one batch. Each batch is its own window.

## Phase 4 — Running

- **🔷** `✔️` **Run** saves the task (`is_draft` 0) and disables the Run button.
- **🔷** `✔️` The planning body is replaced by one terminal per ticked machine. Tabs sit along the bottom of this window. These terminals are not main-window tabs, and they do not use `Session.Controller.create`.
- **🔷** `✔️` Each terminal logs in with the existing SSH login, then `sudo -i` when that host has it. This step does not run `lxc-console`.
- **🔷** `✔️` While shells are coming up, the title is `starting n/N` with no dots. After every target has attached or failed login, one countdown says `about to run` and three dots, one per second, then the bodies start. Then the title is `running`. `completed` is only when every target has finished.
- **🔷** `✔️` After every target has attached (or failed login), the title is `about to run` and three `.` characters. One `.` is removed each second. After three seconds the bodies are sent and the title becomes `running`. See `docs/bugs/done/2026-11-18-FIXED-script-sender-wait-before-attach.md`.
- **🔷** `✔️` Run stays on the left. The right-hand button is **Cancel** while a run is in progress, and **Close** otherwise. They are never both shown. Cancel stops the jobs and reveals Close. Close is what dismisses the window.
- **ℹ️** Cancel after sending stops the next line. A prompt wait already in `expect` runs until it returns. These hunks do not interrupt it.
- **💩** A target stopped mid-send gets `is_cancelled`, `ended`, and a non-zero `success`.
- **ℹ️** The ssh process stays open, so VTE `child_exited` is not the last command's exit code. This plan does not send `echo $?`.
- **🔷** `✔️` `lxc-attach` for a container runs as soon as the shell is up. The body is `Batch.inject` after the dots, unless Cancel was pressed. Each line is `inject_line`.
- **🔷** `✔️` When **success criteria** is set, the text from the last command to the next prompt is matched with that regex.
  - A match puts a green tick on that tab.
  - No match finishes the machine with no tick.
  - Empty criteria still counts as success when the prompt returns, and that tab gets no green tick.
- **🔷** `✔️` After each target finishes, the top bar is `completed 8/10` when success criteria is empty, or `completed 8/10 - success 4/10` when it is set.
  - `completed 8/10` is finished out of selected.
  - `success 4/10` is passed out of selected, and only when criteria is set.
- **🔷** `✔️` One terminal per target, all started together, all inside this batch window.
- **🔷** `⏳` A machine list shows each target: logging in, running, done, or failed. Picking a row shows that terminal.
  - **ℹ️** These hunks do not add a second list. The tab strip is the switcher. Per-row words are still open.
- **🔷** `✔️` The other terminals keep running while you look at one.
- **ℹ️** The batch does not show which command line is in flight. Blank lines are still skipped when sending.
- **🔷** `⏳` Login is the `OpenSession` flow: spawn `ssh` to the host (the parent host for an LXC row), password / passphrase / host-key confirm / verification, then `sudo -i` when `sudo_after_login` is set.
- **🔷** `⏳` Present and focus the **batch** window for that login. Do not raise the main drop-down.
  - **ℹ️** No hunk here. `SshLogin.on_content` still presents the main window for host-key and verification. Do not change that in this completion.
- **🔷** `✔️` After the shell (and sudo, when set), an LXC target is `lxc-attach -n NAME`, then wait until the cursor moves off that row and the next prompt is a shell or a root prompt. Not `lxc-console`. The prompt already on screen is not the attach prompt.
- **🔷** `✔️` Then the title is `about to run` plus three dots, one per second. Then each remaining line is fed, and the job waits for the next shell or root prompt before the next line. A prompt bumps `identifier`.
- **🔷** `✔️` The last line sets `ended`. `success` is 0 when `success_regex` is empty or the regex matches. A missed regex, a timeout, or a failed login sets `ended` and a non-zero `success`, and leaves the terminal on screen. Save already rejected a bad pattern, so inject does not catch `RegexError`.
- **💩** `✔️` One machine failing does not stop the others.
- **🔷** `✔️` When every target has `ended` set, `task.completed` is set. The window stays up.
- **🔷** `✔️` **Close** kills each batch ssh process. The window still hides, so Shell Hide keeps working. Main-window sessions stay.

### 6. `src/Dialog/Plan.vala` — `append_job`, `feed`, `finish`

**Why:** `append_job` is the body of the host loop. `feed` starts injection. `finish` updates the title and the tick.

**Where:** new methods immediately above `refresh_select`.

**Depends on:** §1, §6.

#### Add

Above `private void refresh_select()`. `append_job` builds one target. `feed` starts inject once. `finish` sets the title with `printf`.

```vala
		/**
		 * Open one ticked host and keep the job on {@link jobs}.
		 *
		 * @param conn host or container to run
		 * @param tabs terminal pages in this window
		 * @param strip tab buttons along the bottom
		 */
		private void append_job(Host.Connection conn, Adw.TabView tabs, Gtk.Box strip)
		{
			var rows = new Gee.ArrayList<RooTerm.SQT.TaskTarget>();
			RooTerm.SQT.TaskTarget.query(this.main.tree.db).select(
				"WHERE id = " + this.picks.get((int) conn.id).to_string(),
				rows);
			if (rows.size == 0) {
				return;
			}
			var target = rows.get(0);
			target.started = (int64) new GLib.DateTime.now_local().to_unix();
			this.targets.save(target);
			var term = new Terminal.Ssh(conn, this.main.config);
			var page = tabs.append(term);
			page.title = conn.name;
			var tick_icon = new Gtk.Image.from_icon_name("emblem-ok-symbolic") {
				visible = false
			};
			var chip_box = new Gtk.Box(Gtk.Orientation.HORIZONTAL, 6);
			chip_box.append(new Gtk.Label(conn.name));
			chip_box.append(tick_icon);
			var chip = new Gtk.Button() {
				child = chip_box,
				tooltip_text = conn.name
			};
			chip.add_css_class("flat");
			chip.clicked.connect(() => {
				tabs.selected_page = page;
			});
			strip.append(chip);
			var job = new Jobs.Batch(this.main, conn, term) {
				script = this.script,
				target = target,
				page = page,
				chip = chip,
				tick_icon = tick_icon
			};
			this.jobs.add(job);
			job.run.begin((obj, res) => {
				try {
					job.run.end(res);
				} catch (Jobs.Error e) {
					GLib.warning("batch open failed name=%s: %s",
						conn.name, e.message);
					target.ended = (int64) new GLib.DateTime.now_local().to_unix();
					target.success = 1;
					this.targets.save(target);
					this.finish(job);
					return;
				}
				this.opened++;
				if (this.finished == 0 && !this.sending) {
					this.title = "executing .... %d/%d".printf(this.opened, this.goal);
				}
				if (!this.sending) {
					return;
				}
				this.feed(job);
			});
		}

		/**
		 * Start {@link Jobs.Batch.inject} once this shell is up.
		 *
		 * A stopped run, a job already feeding, or a shell that is
		 * not up yet does nothing.
		 *
		 * @param job batch login for one machine
		 */
		private void feed(Jobs.Batch job)
		{
			if (this.stopped || job.feeding) {
				return;
			}
			if (job.current_state != Jobs.Job.State.DONE) {
				return;
			}
			job.feeding = true;
			job.inject.begin((obj, res) => {
				try {
					job.inject.end(res);
				} catch (GLib.Error e) {
					GLib.warning("batch inject failed name=%s: %s",
						job.connection.name, e.message);
					job.passed = false;
					job.tick = false;
					job.target.ended = (int64) new GLib.DateTime.now_local().to_unix();
					job.target.success = 1;
					this.targets.save(job.target);
				}
				this.finish(job);
			});
		}

		/**
		 * One target has finished. Update the title and the tick.
		 *
		 * The title is ``completed 8/10 - success 4/10``.
		 * Finished out of selected, then passed out of selected.
		 * The last finish sets ``task.completed``.
		 *
		 * @param job machine that just finished
		 */
		private void finish(Jobs.Batch job)
		{
			this.finished++;
			if (job.passed) {
				this.passed++;
			}
			if (job.tick) {
				job.tick_icon.visible = true;
			}
			this.title = "completed %d/%d - success %d/%d".printf(
				this.finished,
				this.goal,
				this.passed,
				this.goal
			);
			if (this.finished < this.goal) {
				return;
			}
			this.task.completed = (int64) new GLib.DateTime.now_local().to_unix();
			this.tasks.save(this.task);
		}
```

```vala
		/**
		 * Feed {@link RooTerm.SQT.Script.body} after the shell is up.
		 *
		 * An LXC row runs ``lxc-attach`` first. Blank lines are
		 * skipped. Each other line is {@link inject_line}. The text
		 * from the last line to that prompt is matched with
		 * {@link RooTerm.SQT.Script.success_regex}.
		 *
		 * Empty ``success_regex`` counts as success and does not tick.
		 * A match ticks and stores ``success`` 0. A miss, a
		 * timeout, or {@link halt} stores a non-zero ``success``.
		 */
		public async void inject() throws Error, GLib.RegexError
		{
			this.tick = false;
			this.passed = false;
			if (this.halt) {
				this.target.is_cancelled = true;
				this.target.success = 1;
				this.target.ended = (int64) new GLib.DateTime.now_local().to_unix();
				this.targets.save(this.target);
				return;
			}
			if (this.connection.kind == Host.ConnectionKind.LXC) {
				this.current_state = State.UNKNOWN;
				this.terminal.terminal.feed_child(
					("lxc-attach -n " + this.connection.lxc_name + "\n").data);
				if (!yield this.expect(State.WAIT_SHELL_PROMPT, 60000)) {
					throw new Error.TIMEOUT("lxc attach timeout name=%s".printf(
						this.connection.name));
				}
			}
			var parts = this.script.body.split("\n");
			var text = "";
			for (var i = 0; i < parts.length; i++) {
				if (this.halt) {
					this.target.is_cancelled = true;
					this.target.success = 1;
					this.target.ended = (int64) new GLib.DateTime.now_local().to_unix();
					this.targets.save(this.target);
					return;
				}
				var line = parts[i].replace("\r", "");
				if (line.strip().length == 0) {
					continue;
				}
				text = yield this.inject_line(line);
			}
			this.passed = true;
			this.target.success = 0;
			if (this.script.success_regex.strip().length == 0) {
				this.target.ended = (int64) new GLib.DateTime.now_local().to_unix();
				this.targets.save(this.target);
				this.current_state = State.DONE;
				return;
			}
			this.passed = false;
			this.target.success = 1;
			var check = new GLib.Regex(this.script.success_regex);
			GLib.MatchInfo info;
			if (check.match(text, 0, out info)) {
				this.passed = true;
				this.tick = true;
				this.target.success = 0;
			}
			this.target.ended = (int64) new GLib.DateTime.now_local().to_unix();
			this.targets.save(this.target);
			this.current_state = State.DONE;
		}

		/**
		 * Feed one command line and wait for the shell prompt.
		 *
		 * Bumps {@link RooTerm.SQT.TaskTarget.identifier}. Returns
		 * the text from this line to the next prompt.
		 *
		 * @param line one non-blank line from the script body
		 * @return the terminal text for this line
		 */
		private async string inject_line(string line) throws Error
		{
			long start_col, start_row;
			this.terminal.terminal.get_cursor_position(out start_col, out start_row);
			this.current_state = State.UNKNOWN;
			this.terminal.terminal.feed_child((line + "\n").data);
			if (!yield this.expect(State.WAIT_SHELL_PROMPT, 60000)) {
				throw new Error.TIMEOUT("command timeout name=%s".printf(
					this.connection.name));
			}
			this.target.identifier++;
			this.targets.save(this.target);
			long end_col, end_row;
			this.terminal.terminal.get_cursor_position(out end_col, out end_row);
			size_t sample_len;
			var sample = this.terminal.terminal.get_text_range_format(
				Vte.Format.TEXT, start_row, 0, end_row, end_col, out sample_len);
			if (sample == null) {
				return "";
			}
			return sample;
		}
```
