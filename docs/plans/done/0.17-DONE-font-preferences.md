 * VTE font family. Empty = system monospace family

[Description(nick = "Font family", blurb = "Monospace font family (empty = system)")]

**ℹ️** ``Session.Controller.terminal_font`` can stay a composed Pango string for create paths, or terminals read ``config`` only — pick one at implement time; prefer composing once at apply sites (Base + session create) so empty family always resolves live.

### System family resolve (inline — no helper)

```vala
var family = "Monospace";
var schema = GLib.SettingsSchemaSource.get_default().lookup(
	"org.gnome.desktop.interface", true
);
if (schema != null) {
	var desc = Pango.FontDescription.from_string(
		new GLib.Settings.full(schema, null, null).get_string("monospace-font-name")
	);
	if (desc.get_family() != null && desc.get_family().length > 0) {
		family = desc.get_family();
	}
}
```

Compose for VTE:

```vala
var face = config.font_family.length > 0 ? config.font_family : /* system family */;
var pango = "%s %d".printf(face, config.font_size);
// terminal.font_desc = Pango.FontDescription.from_string(pango);
```

## Row — font family (`RowFontFamily`)

Mirror ``RowThemeSelect`` shape: ← | ``Adw.ComboRow`` | →.

- **🔷** Model: list of monospace family names + leading **System** sentinel (stored value ``""``; display label ``System`` — System label uses default UI font, not a face).
- **🔷** Build list from ``Pango.CairoFontMap.get_default()`` / display font map: families where ``is_monospace()``; sort by name.
- **🔷** Combo / list cells: family name **rendered in that font** (``Gtk.SignalListItemFactory`` → ``Gtk.Label`` with ``attributes`` / font-desc for that family). System row: plain “System”.
- **🔷** ← → cycle selection (same guards as theme row).
- **🔷** ``send`` empty string for System; else family name.
- **🔷** Bound to ``font-family``.

### Wire

```vala
var font_family = new RowFontFamily(this.config, "font-family");
this.add("font-family", font_family, font_group);
```
