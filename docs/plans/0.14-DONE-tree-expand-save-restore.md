## Purpose

- **🔷** Persist expand/collapse only for **groups** and **LXC hosts** (``lxc_host``) in `connections.json`.
- **🔷** Save when the user expands or collapses one of those rows.
- **🔷** On launch, restore expand state for those rows.
- **🔷** Localhost is **always expanded** on load — do not persist its expand state.

---

## Behaviour (shipped)

- **✔️** `Connection.expanded` (default ``true``); ``expand_binding`` / ``expand_save_sid`` slots (not JSON).
- **✔️** `TreeListModel` ``autoexpand = false``.
- **✔️** `factory.bind`: ``bind_property`` for ``GROUP`` / ``lxc_host``; Localhost forced open; ``unbind`` drops binding.
- **✔️** `TreeNodes.append` / ``remove``: ``notify["expanded"]`` → ``config.save()`` for ``GROUP`` / ``lxc_host``.
- **✔️** `tree.config` set before nest fill (JSON load, Ásbrú ``to_config``, empty MainWindow config).
