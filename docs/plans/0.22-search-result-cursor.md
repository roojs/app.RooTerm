## Purpose

- **🔷** Search results need a **secondary selection highlight** on the row.
- **🔷** Up / Down in the **search area** walk the potential results.
- **🔷** Enter **picks** that highlighted row.
- **🔷** Do **not** use `Gtk.SingleSelection` / ListView selection for the walk.
- **ℹ️** That selection is the **active terminal**. Arrowing search must not steal it.
- **✔️** Land the fences below after this review.

---

## Current behaviour

- **ℹ️** `MainWindow.host_search` text binds to `Host.Tree.search`.
- **ℹ️** Non-empty search sets `show_all`, fills `search_uuids`, refilters, `expand_all`.
- **ℹ️** ListView `selection` is the session row. Clicking it can clear search.
- **ℹ️** Secondary chrome already exists: `menu_target` + `.menu-target` on the expander.

---

## Proposed behaviour

- **🔷** A second list, `search_hits`, is every **visible non-group** row.
- **🔷** Name match, parent of a match (the host around a container), and children of a match (containers under a host) are all walkable.
- **🔷** Groups stay on the filter path; they are **not** on `search_hits`.
- **🔷** `search_target` is the current hit. Not ListView `selection`.
- **🔷** `Connection.search_css` is `""` or `"search-target"`. Factory binds it to the expander `name` (same PropertyExpression chain as `name` / `tree-icon`). Writing the node restyles the row (`treeexpander#search-target`).
- **🔷** Leaving search: set `search_css` to `""` on the current node, then drop `search_target`.
- **🔷** Focus stays in the search entry. Down / Up call `search_step`. Enter calls `search_pick`.
- **🔷** `search_uuids` stays the filter set (matches + parent path).
- **🔷** `search_step` wraps: past the last hit → first; before the first → last.
- **💩** First result: after `expand_all`, one `Idle.add` → `search_step(1)` (idle so `tree_row` exists for scroll).
- **💩** Enter: `select()` if the row has a session; otherwise `connection_activated`.

## 4. `src/Host/Tree.vala` — `search_step` / `search_pick` ✔️

**Why:** The walk and Enter must not live in `Tree()`. This plan names these two methods.

**Where:** after `select()`, before `Tree()`.

**Depends on:** §2, §3.

#### Add — New methods between `select` and the constructor.

```vala
		/**
		 * Move {@link search_target} by ``delta`` entries in {@link search_hits}.
		 * Does not change {@link selection}. Wraps past either end.
		 *
		 * @param delta ``1`` Down, ``-1`` Up
		 */
		private void search_step(int delta)
		{
			if (this.search == "" || this.search_hits.size == 0) {
				return;
			}
			var i = -1;
			if (this.search_target != null) {
				i = this.search_hits.index_of(this.search_target);
			}
			if (i < 0) {
				i = delta > 0 ? -1 : this.search_hits.size;
			}
			i += delta;
			if (i < 0) {
				i = this.search_hits.size - 1;
			}
			if (i >= this.search_hits.size) {
				i = 0;
			}
			var hit = this.search_hits.get(i);
			if (hit == this.search_target) {
				return;
			}
			if (this.search_target != null) {
				this.search_target.search_css = "";
			}
			this.search_target = hit;
			this.search_target.search_css = "search-target";
			if (this.search_target.tree_row == null) {
				return;
			}
			this.list_view.scroll_to(this.search_target.tree_row.get_position(), Gtk.ListScrollFlags.NONE, null);
		}

		/**
		 * Apply the search cursor: select an open row, otherwise activate.
		 */
		private void search_pick()
		{
			if (this.search_target == null) {
				return;
			}
			if (this.search_target.sessions.get_n_items() > 0) {
				this.select(this.search_target);
				return;
			}
			this.connection_activated(this.search_target);
		}
```

			this.notify["search"].connect(() => {
				this.search_uuids.clear();
				this.search_hits.clear();
				if (this.search_target != null) {
					this.search_target.search_css = "";
				}
				this.search_target = null;
				if (this.search == "") {
					this.open_filter.changed(Gtk.FilterChange.DIFFERENT);
					hint.visible = !this.show_all && window.tree.num_open > 0;
					window.tree.expand_all();
					return;
				}
				var needle = this.search.casefold();
				foreach (var conn in window.tree.by_uuid.values) {
					if (!conn.name.casefold().contains(needle)) {
						continue;
					}
					this.search_uuids.add(conn.uuid);
					var up = conn.parent;
					while (up != null) {
						this.search_uuids.add(up.uuid);
						up = up.parent;

				var pending = new Gee.ArrayList<Connection>();
				for (var i = window.tree.size - 1; i >= 0; i--) {
					pending.add(window.tree.get(i));
				}

						pending.add(conn.children.get(c));

						continue;

						continue;

					var up = conn.parent;
					while (up != null) {
						if (up.name.casefold().contains(needle)) {
							this.search_hits.add(conn);
							break;
						}
						up = up.parent;
					}
				}
				this.show_all = true;
				this.open_filter.changed(Gtk.FilterChange.DIFFERENT);
				hint.visible = false;

					this.search_step(1);
					return false;
				});

## LLM notes

- **🚫** Do not put the walk inline in `Tree()`. Use `search_step` / `search_pick` as named above.
- **🚫** Do not scan `tree_model` in `search_step` or in `items_changed` to find hits.
- **🚫** Do not wrap the row in `Gtk.Overlay` (or any extra fill widget) for the highlight.
- **🚫** Do not copy `menu_target` (`set_data` + `notify` on the expander) for the search cursor.
