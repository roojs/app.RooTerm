---

## Layout (XDG data)

```
~/.local/share/rooterm/sessions/<uuid>/index.json
~/.local/share/rooterm/sessions/<uuid>/<YYYY>/<MM>/<stamp>-input.log
~/.local/share/rooterm/sessions/<uuid>/<YYYY>/<MM>/<stamp>-vte.log
```

- **🔷** Per connection `uuid`: `index.json` lists past sessions (prompt + datetime + relative paths) for the pulldown.
- **🔷** Files under `YYYY/MM/` only.
- **🔷** Two files per stopped session: `*-input.log` (typed; redacted secrets) + `*-vte.log` (flush of 500-line ring).
- **🚫** Store under `~/.config` or `~/.cache`; **🚫** unbounded in-memory history.
- **ℹ️** Today some SSH logs still go under Ásbrú `session_logs` — migrate to the layout above.

---

## Behaviour

1. **🔷** Input stream — append typed lines under the path above.
2. **🔷** VTE rotating log — in-memory 500-line ring; on stop flush to `*-vte.log` and update `index.json`.
3. **🔷** History pulldown → feed `*-vte.log` into a read-only VTE.
4. **🔷** Losing the in-memory ring on crash is acceptable; flush on orderly stop / dead / user close.
