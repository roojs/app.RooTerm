# 0.1 — RooTerm base plan

**Status:** DONE

**Pointer:** `docs/guide-to-writing-plans.md` — **Checklist for plans**; proposed Vala follows **`docs/coding-standards.md`** (use **`docs/coding-standards-router.md`** when implementing). Build: **`docs/build-rules.md`**.

## Purpose

- **🔷** Small **GTK4** + **LibVTE** app that reads the existing **Ásbrú CM** config and shows a connection tree + terminals — without touching Ásbrú’s Perl codebase.
- **🔷** Follow **OLLMchat** application + debug design: `Application` / `--debug` / `--debug-critical`, `GLib.Log` handler → **`~/.cache/rooterm/{app_id}.debug.log`** (same idea as `OLLMchat.ApplicationInterface.debug_log`).
- **🔷** Layout: header **“Roo Term”** on the left, **host search top-center** (OLLMchat-style searchable pulldown, not stock combo); host **tree** on the left; right side = **host `Gtk.Stack`** with a **per-host terminal stack + tab bar**.
- **🔷** **Single-click** a host: **highlight only** (Ásbrú-like). **Double-click**: open a **new** terminal tab on that host.
- **🔷** **Ctrl+Shift+O** focuses search; typing filters a custom popover list and jumps/selects hosts (e.g. `SG1`).
- **🔷** Search **placeholder**: idle hint **`Ctrl+Shift+O`**, or when a session is focused show **`{name}  {cwd}`** as the placeholder background (header left stays **Roo Term** only — do not duplicate the host name there).
- **🔷** OS **window title** (what window-logger sees): focused session **`{name}` + cwd** when known; **`Roo Term`** when nothing is open.
- **🔷** Tab labels: **host `name`** + **working directory** when known (no Ásbrú `all - …` titles).
- **🔷** Decrypt Ásbrú password blobs (Blowfish / Crypt::CBC) — needed for real logins.
- **🔷** Send decrypted Ásbrú **password** into the SSH login prompt (simple VTE feed on password prompt) — **no** Expect binary, **no** Ásbrú expect-list import.
- **🔷** `✔️` Phases 1–5 base behaviour done.
- **ℹ️** Config: `~/.config/asbru/asbru.yml`. Cipher in `/opt/asbru/lib/PACUtils.pm`. OLLMchat refs: `libollmchat/ApplicationInterface.vala`, `liboccoder/SearchableDropdown.vala`, `ollmapp/SettingsDialog/SearchablePulldown.vala`.

## Current behaviour (Ásbrú pain)

- **🔷** We mainly use the left host list + right terminal.
- **🔷** Activating a host often spawns yet another terminal → duplicate clutter.
- **🔷** Window title is always Ásbrú → useless for activity logs (we expose **host + cwd** on the real window title instead).
- **🔷** Ásbrú titles like `all - hostname` are noisy and pointless.

## Proposed behaviour

### Layout

```
┌─ Roo Term ── [ sg1  ~/proj | Ctrl+Shift+O ] ────────────┐
├──────────────────┬──────────────────────────────────────┤
│ tree             │  [ tab: name ~/path ] [ tab: … ]     │  ← per-host tab bar
│  ▸ all           │ ┌──────────────────────────────────┐ │
│      sg1   ▣▣ │ │ VTE for selected tab             │ │
│      fab    ▣ │ └──────────────────────────────────┘ │
└──────────────────┴──────────────────────────────────────┘
```

- **🔷** Header: app title **Roo Term** left only (not the host name again); **search top-center**.
- **🔷** Left: Ásbrú-like tree (groups + connections), **sorted alphabetically by `name`** within each parent (and roots).
- **🔷** Optional trailing marks on rows for “has open session(s)” — keep minimal (dot / count); **tabs** are the real multi-session UI.
- **🔷** Right pane:
  - **Outer `Gtk.Stack`**: one page per **host that has ≥1 open terminal**.
  - **Inner** (per host): **tab bar + `Gtk.Stack`** of terminals; each tab has a small toolbar strip if needed — keep thin for 0.1.
- **🔷** Keep the first cut simple: no fancy session-icon column chrome beyond a light “open” hint if easy.

### Open / focus (Ásbrú-like)

- **🔷** **Single-click** connection → **select / highlight only**. Does **not** spawn. Does **not** by itself open a terminal.
- **🔷** **Double-click** connection → spawn a **new** `SshTerminal` tab under that host (create host stack page if needed) and focus it.
- **🔷** Single-click on a host that **already has** a stack page → switch outer stack to that host (still no spawn).
- **🔷** Switching terminals on the same host → **tabs** (and/or stack children).

### Search / jump (OLLMchat-style pulldown)

- **🔷** **Ctrl+Shift+O** → focus the search entry (select-all / ready to type).
- **🔷** Do **not** use stock `Gtk.DropDown` / plain `Gtk.SearchEntry` alone for the host picker.
- **🔷** Use an OLLMchat-style **searchable pulldown**: `Gtk.Entry` + custom **`Gtk.Popover`** + **`Gtk.ListView`** / filter model (same family as `SearchableDropdown` / `SearchablePulldown`) — friendlier than the default GTK suggestion UI.
- **🔷** Typing filters the popover list live (case-insensitive substring on `name`; list **A–Z**).
- **🔷** **Up / Down** move the **highlight** in the popover only (do **not** select in the tree / open anything). **Enter** (or click a row) **commits**.
- **🔷** On commit from search:
  - Highlight the host in the tree.
  - If that host has **no** open terminals → **open** one (same as double-click).
  - If it **already has** ≥1 terminal → **show** that host page and focus the **first** tab (no new spawn).
- **🔷** Placeholder when the entry is empty:
  - If a terminal session is focused → show **`{name}  {cwd}`** (cwd omitted until known).
  - Else → show **`Ctrl+Shift+O`** so the shortcut is discoverable.
- **🔷** Tooltip always mentions Ctrl+Shift+O (even when the placeholder shows host+cwd).
- **ℹ️** Precedent: `OLLMchat/liboccoder/SearchableDropdown.vala`, `OLLMchat/ollmapp/SettingsDialog/SearchablePulldown.vala`.

### Titles

- **🔷** Header left label: **`Roo Term`** only (host already visible in tree / tabs / search placeholder).
- **🔷** **Window title** (toplevel `title` for window-logger): focused session display string **`{name}`** + cwd when known; if no session → **`Roo Term`**.
- **🔷** Tab title: same **`{name}`** (+ cwd) idea; use Ásbrú **`name`**, not `title` (`all - …`).
- **💩** CWD source: OSC 7 / VTE title updates from the shell when available; until then name only.

### Application + debug (OLLMchat pattern)

- **🔷** Mirror OLLMchat app wiring:
  - `Gtk.Application` / Adw if we use it; `OptionEntry` for **`-d` / `--debug`** and **`--debug-critical`**
  - `GLib.Log.set_default_handler` → write **`~/.cache/rooterm/{app_id}.debug.log`** (truncate on open), stderr when debug on; criticals always eligible
  - `GLib.debug()` / `GLib.warning()` at real control-flow points — follow **`docs/coding-standards.md`** debug rules (no class/method prefixes, no timestamps in the message, no throttle/gate helpers)
- **ℹ️** Precedent: `OLLMchat/libollmchat/ApplicationInterface.vala` (`debug_log`), `OLLMchat/ollmapp/Application.vala`.

### Config + cipher

- **🔷** Read-only `~/.config/asbru/asbru.yml`.
- **🔷** SSH only in 0.1.
- **🔷** Decrypt `pass` / `passphrase`.
- **ℹ️** Ásbrú cipher (`PACUtils.pm` / `PACMain.pm`):
  - `Crypt::CBC`, cipher **Blowfish**, PBKDF **opensslv1**
  - key string: `PAC Manager (David Torrejon Vaquerizas, david.tv@gmail.com)`
  - salt: `pack('Q', '12345678')` with `$SALT = '12345678'`
  - stored as **hex**; plaintext ciphertext often begins with OpenSSL `Salted__`
  - API used: `encrypt_hex` / `decrypt_hex`
- **🔷** Implement matching decrypt in RooTerm in **Vala** via a thin **`vapi/libgcrypt.vapi`** (object-style `Md` / `Cipher`) + Ásbrú `Salted__` / opensslv1 glue in `AsbruCipher`.
- **🚫** Do not maintain Ásbrú Perl.

### VTE / SSH login

- **🔷** LibVTE PTY + `spawn_async` (or equivalent) for `ssh`.
- **🚫** No Expect binary; **no** Ásbrú `expect` list import.
- **🔷** When auth needs a password: detect the SSH password prompt in VTE and **feed** decrypted `connection.pass` (once); passphrase for keys similarly if needed.
- **🔷** Child-exited → drop tab/session.

## Class list (0.1)

Keep names short; wrap VTE; one connection model; stacks own sessions.

- **`Application`** — `Gtk.Application` (+ Adw if used); `--debug` / `--debug-critical`; log handler → `~/.cache/rooterm/….debug.log`; action `win.search` → Ctrl+Shift+O.
- **`MainWindow`** — header (**Roo Term** + host search pulldown), paned tree | session area; updates **window title** from focused session.
- **`HostTree`** — tree UI; A–Z by name; single-click select; double-click → open session; open-session markers.
- **`HostSearchPulldown`** — OLLMchat-style entry + popover list; Up/Down highlight only; Enter/click → open-or-focus; placeholder Ctrl+Shift+O or `{name} {cwd}`.
- **`AsbruConfig`** — load `asbru.yml` with libyaml; build connection tree.
- **`Connection`** — one class for groups and hosts; **`is_group`** flag; uuid, name, parent, method, ip, port, user, auth fields (decrypted when needed).
- **`AsbruCipher`** — Vala + `vapi/libgcrypt.vapi` Blowfish/CBC hex decrypt matching Ásbrú.
- **`SessionController`** — which hosts have pages; focused host/tab; open / close / focus; session display string for title/placeholder.
- **`HostStack`** — outer `Gtk.Stack` keyed by connection uuid.
- **`HostPage`** — one host: tab bar + inner `Gtk.Stack` of `SshTerminal`s; tab labels updated on the bar (no separate tab class).
- **`SshTerminal`** — wraps `Vte.Terminal`; spawn SSH from `Connection`; exposes cwd hint when known; child-exited.

**🚫** Separate `Group` class — use `Connection.is_group`.  
**🚫** Separate `TerminalTab` class — `HostPage` owns the tab bar + stack children.  
**💩** Share/copy a trimmed pulldown base from OLLMchat vs implement a RooTerm-only slim `HostSearchPulldown`.

## Phases

### Phase 1 — Scaffold

- **🔷** `✔️` Meson + GTK4 `Application` with `--debug` / `--debug-critical` → `~/.cache/rooterm/{app_id}.debug.log`.
- **🔷** `✔️` Window header: **Roo Term** left + empty search center; window title starts as **Roo Term**.
- **🔷** `✔️` Link VTE GTK4; one local shell in a throwaway stack page (sanity).

### Phase 2 — Config + tree

- **🔷** `✔️` `AsbruConfig` (libyaml) / single `Connection` model (`is_group`).
- **🔷** `✔️` `AsbruCipher` decrypt for `pass` / `passphrase`.
- **🔷** `✔️` `HostTree` from groups/SSH connections (`name`, not `all -` title).

### Phase 3 — Host stack + terminal tabs

- **🔷** `✔️` `SessionController` + `HostStack` + `HostPage` + `SshTerminal`.
- **🔷** `✔️` Single-click = highlight only; double-click = new tab / new host page.
- **🔷** `✔️` Tab labels (on `HostPage`) + **window title** + search placeholder track focused `{name}` (cwd in Phase 5).
- **🔷** `✔️` Single-click switches outer stack when host already open.

### Phase 4 — Host search pulldown

- **🔷** `✔️` `HostSearchPulldown` (OLLMchat entry+popover pattern).
- **🔷** `✔️` Ctrl+Shift+O focuses it; placeholder `Ctrl+Shift+O` or session `{name} {cwd}`.
- **🔷** `✔️` Filter list (case-insensitive substring on `name`).
- **🔷** `✔️` Open-or-focus commit + Up/Down highlight (Phase 5).

### Phase 5 — Sort, search commit, password, markers, cleanup, cwd

- **🔷** `✔️` **Alphabetical sort** of tree roots and children by `name`; search popover list sorted the same way.
- **🔷** `✔️` Search **Up / Down**: popover **highlight only** (CAPTURE key phase); Enter commits (first row if none highlighted).
- **🔷** `✔️` Search **Enter / row click**: highlight in tree, then **open** if none, else **flip** to host page + first tab.
- **🔷** `✔️` **Password send**: VTE contents match on password/passphrase prompt → feed decrypted secret once.
- **🔷** `✔️` Tree **open-session markers** (one terminal icon per tab; active icon green; click focuses that tab).
- **🔷** `✔️` **child-exited** cleanup (drop tab; remove empty page; clear markers / focus / title / placeholder).
- **🔷** `✔️` **Cwd** from VTE termprop `vte.cwd` → tab / title / placeholder when known.
- **🔷** `✔️` Single-click on a host that already has a page → switch outer stack (still no spawn).
- **🔷** `✔️` Search tooltip always mentions Ctrl+Shift+O.

### Phase 6 — Session logs (smarter than Ásbrú full dump)

- **🔷** `✔️` Log to Ásbrú folder/pattern: `~/.config/asbru/session_logs/<UUID>_<NAME>_<YYYYMMDD>_<HHMMSS>.txt`.
- **🔷** `✔️` Log **typed input** (VTE `commit`); omit password/sudo/passphrase entry (`[password omitted]`).
- **🔷** `✔️` Auto-fed SSH secrets are not written to the log.
- **🔷** `✔️` **Minimal output**: at most the first short plain line after Enter; skip noisy / escape-heavy bursts (`top`, etc.).
