# 0.20 — Last tab per workspace

**Status:** ✔️ implemented (awaiting user verify)

**Pointer:** `docs/guide-to-writing-plans.md` — **Checklist for plans**; Vala via **`docs/coding-standards-router.md`**. Build: **`docs/build-rules.md`**. GNOME Shell: **`docs/coding-standards-gnome-shell.md`**.

**ℹ️** Next number after **0.19** find / open hosts.
**ℹ️** Overlay already `stick()`s on every GNOME workspace (`resources/extension/Dock.js`).
**🔷** Small change: cache the desktop index, remember a uuid per desktop, restore that tab on show.

Edits are **Remove** / **Replace with** / **Add** from the tree;
verify surrounding context before applying.

---

## Purpose

- **🔷** Work on **different GNOME workspaces** (virtual desktops): one project per desktop.
- **🔷** **F1** (hide, then later show) on a workspace should bring back the **tab that was active last time that workspace showed the overlay**.
- **🔷** Hide on workspace A, switch to workspace B, **F1** → restore B’s last tab.
- **🔷** Hide on B, switch back to A, **F1** → restore A’s last tab.
- **🔷** Leave the overlay **open** and flip workspaces → **do not** switch tabs. Same tab stays visible.
- **🔷** Persist that map in **`config.json`**, so after quit + tab restore, opening on workspace 1 still selects workspace 1’s last tab.
- **🔷** Preferences: on/off for this behaviour. **Default on**.
- **✔️** Fences applied.

---

## Current behaviour

- **ℹ️** One drop-down, one selected host page + one selected VTE tab, globally.
- **ℹ️** Hide / show (`F1`, panel, `rooterm --toggle`) does not change which tab is selected.
- **ℹ️** Dock calls `win.stick()` so the overlay is on **all** workspaces. Leave it open and switch desktop → you still see the same tab. That part is already right.
- **ℹ️** App `DBus.toggle` only asks Shell to `toggle('main')`. Shell decides show vs hide. The app is not told the active workspace.

## Proposed behaviour

### Restore only after hide

- **🔷** Remember last tab **per workspace**.
- **🔷** Any **activation** of a tab (open, close → new selection, click, next/prev) updates the maps for the **current** workspace.
- **🔷** **Restore** when the overlay **shows** after being hidden, using the workspace you are on **now**.
- **🔷** If the overlay **stays visible** while you switch workspace: no restore, no tab change. (Maps for the old desktop already have the last activation.)
- **🔷** First show on a workspace with nothing stored: keep whatever tab is already selected.
- **🔷** Remembered tab is not open: do nothing (keep the current tab).

### Persist in `config.json`

- **🔷** Write the workspace → tab map to **`config.json`** (not session-only).
- **🔷** After restart, once those tabs are open again, **F1** on a workspace restores that workspace’s last tab.
- **🔷** Prefs off: do not **update** the maps on activation. Do not save-on-hide / save-on-quit for this feature. Still **serialize** whatever is already in the uuid map so leftover JSON is not wiped.
- **🔷** Write `config.json` on hide (start of hide) and on quit — maps are already current from activations. `Config.save()`. No “still visible” surface check.
- **🔷** Stored id is **`Connection.uuid`** (`page.current.connection`). LOCAL_PATH uuid for a local tab; host / LXC uuid for SSH.
- **🔷** Two maps on **`Config`**, managed there:
  - `workspace_uuids` — workspace id → uuid (what `config.json` stores)
  - `workspace_tabs` — workspace id → live `Connection` (runtime only)
- **🔷** Load order: `Config.load()` then `TreeNodes.load()`. After connections exist, fill `workspace_tabs` from `workspace_uuids` + `tree.by_uuid`.
- **🔷** Assign both maps on activation (prefs on): `workspace_tabs` and `workspace_uuids` for the cached index.
- **🔷** `Config.save()` still uses `Json.gobject_to_data`. Gee.HashMap is not a JSON-GLib primitive — `serialize_property` writes `workspace-uuids` as a JSON object of string keys (`"0"`, `"1"`, …). Skip `workspace-tabs` in the existing skip list.
- **🔷** Not a workspace field on the tab / `Connection` — the maps are the only place (one host can have two tabs; one tab can be last-used on more than one workspace).
- **ℹ️** Local restore (**0.13**) is keyed by **folder**: `LOCAL_PATH.cwd` in `connections.json`. Startup skips missing dirs, then `open_local(conn)` **reuses that same row** (uuid is already on the JSON object; not regenerated).

### Preferences

- **🔷** Toggle in Preferences to turn this on or off. **Default on**.
- **🔷** Off: F1 show/hide does **not** switch tabs (today’s global tab). Leave-open-and-flip is unchanged either way.
- **🔷** Off: **stop updating** the workspace → tab map. Do **not** wipe what is already in `config.json`.
- **🔷** General page, new **Behaviour** group (Appearance stays geometry). One switch, not a new sidebar page.
- **🔷** `Config` bool `remember-workspace-tab` (nick **Remember tab per workspace**, blurb **On show, restore the last tab used on this desktop**). Default `true`. Missing key in old `config.json` → on.
- **ℹ️** Turning it back on can still restore from that leftover map until the next hide overwrites a workspace.
- **🔷** Add `Dialog.RowSwitch` (same ActionRow + suffix pattern as `RowScale`, `Gtk.Switch`) and parse bool in `Row.send` and `DBus.config_update`.
- **ℹ️** `config_update` is `(ss)` — value is always a string (ints are already `"60"`). Bool is `"true"` / `"false"` because that is the string form of `Gtk.Switch.active`. Not a new wire type.

### What “tab” means

- **🔷** The VTE tab you were looking at — host page **and** that page’s selected terminal.
- **🔷** Restore from **`workspace_tabs`** in `MainWindow.restore()` (early returns). If that `Connection` has `sessions` items, select `sessions.get_item(0)` with the same `get_child_by_name` + `tab_view.get_page(term)` path as tree highlight. Empty `sessions` → tab not open → do nothing.
- **🔷** Several SSH tabs on one host share one uuid → `sessions.get_item(0)` is the first tab. Fine for v1.

### How we know the workspace

- **🔷** GNOME **workspace** (Super+PageUp / overlay flip). Not physical monitors.
- **🔷** Extension watches desktop changes and **D-Bus**es the new index to the app every time it changes.
- **🔷** App keeps **current workspace in memory** on **`MainWindow.workspace`**. Activations assign against that index. Hide and quit write `config.json`. Show restores against it.
- **🔷** D-Bus `workspace(i)` is only the wire: set `window.workspace` when the window exists. Do **not** store the index on `DBus`.
- **🔷** Workspace change while the overlay is **visible**: update the cache only — **do not** switch tabs.
- **🔷** Workspace change while **hidden**: update the cache so the next show restores the right workspace’s tab.
- **🔷** Also send the current index once when the extension enables / the app appears on the bus (so hide/quit work before the first flip).
- **🔷** Shell: `global.workspace_manager` `active-workspace-changed`. App method on `org.roojs.RooTerm.DBus` (`workspace(i)`).
- **🔷** Dynamic workspaces can renumber indices; accept that drift for this version.
- **🔷** Show vs hide: `MainWindow.hidden`. We already own hide/show call sites — set it there. No GDK surface / `ToplevelState`.
- **💩** Other homes for the index (rejected unless you prefer one): `Application` (exists before the window); `Config.workspace` next to the maps (runtime, skip serialize). MainWindow is where tabs are selected.

### SSH on restart

- **🔷** **Skip for 0.20.** Locals already restore (**0.13**). Open SSH `sessions` are not in JSON.
- **ℹ️** SSH / LXC reconnect stays **`docs/plans/0.9-wishlist.md`**. When that lands, this workspace map should select those restored tabs (uuid already stored).

---

## Suggested order

1. **🔷** `✔️` Extension D-Bus on every desktop change; app caches the current workspace (plus once at start).
2. **🔷** `✔️` Config maps + `remember-workspace-tab` + serialize uuid object.
3. **🔷** `✔️` Any tab activation assigns that `Connection` on Config for the cached workspace (prefs on).
4. **🔷** `✔️` On hide and on quit: `Config.save()` (prefs on only).
5. **🔷** `✔️` On show: `MainWindow.restore()` — HashMap lookup, early returns.
6. **🔷** `✔️` Preferences Behaviour switch (`RowSwitch`, bool `config_update`).

## Show / hide / quit

### 7. `src/MainWindow.vala` — `restore()`: HashMap lookup, early returns

**Why:** **🔷** Same restore from `toggle` and `activate`. Early returns keep it flat. Callers stay linear.

**Where:** new method on `MainWindow`, after `show_docked()`.

**Depends on:** ### 3b, ### 4.

#### Add — after `show_docked()`, before the constructor: select this workspace’s last tab if that connection still has a session.
```vala
		/**
		 * Select the last tab for {@link workspace} when the overlay shows.
		 * No-op if the pref is off, nothing is stored, or that tab is not open.
		 */
		public void restore()
		{
			if (!this.config.remember_workspace_tab) {
				return;
			}
			if (!this.config.workspace_tabs.has_key(this.workspace)) {
				return;
			}
			var conn = this.config.workspace_tabs.get(this.workspace);
			if (conn.sessions.get_n_items() == 0) {
				return;
			}
			var term = (Terminal.Base) conn.sessions.get_item(0);
			var name = conn.uuid;
			if (conn.kind == Host.ConnectionKind.LOCAL_PATH) {
				name = conn.parent.uuid;
			}
			var page = this.host_stack.pages.get_child_by_name(name) as Host.Page;
			if (page == null) {
				return;
			}
			this.host_stack.pages.visible_child = page;
			page.tab_view.selected_page = page.tab_view.get_page(term);
			this.sessions.focus();
		}
```
