### Connection / persistence

#### SSH options in Edit Connection

- **🔷** Plain “SSH options” text entry: load/save `connection.options`.
- **🔷** Useful toggles later: fold X11 (`-X` / `-x`), compression (default on?) — low urgency.
- **🚫** Forward agent, “allow remote port connection”, IP protocol — no clear need.
- **🚫** Remote port forwarding / dynamic SOCKS / Ásbrú “advanced” — skip unless asked.
- **🔷** Socks proxy / network settings — very low on the list.

#### Connection dialog layout

- **🔷** One row: connection method + host + port (tighter basic tab).

#### Pick private key

- **🔷** Choose a private key other than the ones we define / auto-create.

#### Per-connection terminal options

- **🔷** Edit prompt/regex (etc.) per connection — interesting later.

#### Other protocols (Ásbrú parity — mostly out)

- **ℹ️** Ásbrú has FTP, RDP, SFTP, serial, Telnet, VNC, WebDAV…
- **🚫** Unlikely we support those; SSH (+ local / LXC) stays the scope unless asked.

#### Remember tree expand / collapse

- **🔷** Persist expanded/collapsed tree rows; restore on launch.

#### Auto-restore open tabs

- **🔷** On quit / close, remember open tabs and restore them next launch.
- **🔷** Start with **local cwd paths** under Localhost; SSH reconnect is a later step (“startup login”).

#### Startup login / reconnect

- **🔷** Nice-to-have: start the app and land back in sessions (login / reconnect) without re-opening everything by hand.

#### Quit confirmation

- **🔷** **Urgent:** confirm before quit when terminals are still open.
