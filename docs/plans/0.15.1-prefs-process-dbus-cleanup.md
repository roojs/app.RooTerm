## Phases

### Phase 1 — Split ``Config.save`` / ``TreeNodes.save``; drop ``Config.connections``

- **🔷** `Config.save()` writes **chrome only** (`config.json`) — not hosts.
- **🔷** Host edits call **`tree.save()`** only.
- **🔷** `Config.connections` kept only so legacy JSON deserializes and sets `need_migrate`; not written to `config.json`.
- **💩** `✔️` Code below — implemented from fences.
- **⏳** User verify: change opacity → only `config.json` mtime; edit host → only `connections.json` mtime.

Edits are **Remove** / **Replace with** / **Add** from the tree.

### 1. `src/Config.vala` — ``save()`` chrome only

**Why:** **🔷** Preferences / chrome must not rewrite the host tree file.

#### Remove
```vala
		/**
		 * Write ``config.json`` (no passwords). Hosts via {@link Host.TreeNodes.save}.
		 * Write failures log a warning only.
		 */
		public void save()
		{
			var config_path = GLib.Path.build_filename(
				GLib.Environment.get_home_dir(), ".config", "rooterm", "config.json"
			);
			try {
				GLib.FileUtils.set_contents(
					config_path, Json.gobject_to_data(this, null)
				);
			} catch (GLib.Error e) {
				GLib.warning("config save failed: %s", e.message);
				return;
			}
			this.tree.save();
			GLib.debug("saved connections=%d", this.tree.by_uuid.size);
		}
```

#### Replace with
```vala
		/**
		 * Write ``config.json`` only (chrome / preferences). Hosts: {@link Host.TreeNodes.save}.
		 * Write failures log a warning only.
		 */
		public void save()
		{
			var config_path = GLib.Path.build_filename(
				GLib.Environment.get_home_dir(), ".config", "rooterm", "config.json"
			);
			try {
				GLib.FileUtils.set_contents(
					config_path, Json.gobject_to_data(this, null)
				);
			} catch (GLib.Error e) {
				GLib.warning("config save failed: %s", e.message);
				return;
			}
			GLib.debug("saved config.json");
		}
```

### 4. `src/Config.vala` — keep ``connections`` ArrayList for migrate deserialize

**Why:** **🔷** JSON-GLib only calls `deserialize_property` for **known** properties. Without ``connections`` on Config, the key is skipped, ``need_migrate`` never flips, and migration never runs. Keep the list for one-shot migrate; **do not** serialize it to ``config.json``.

#### Keep — property
```vala
		public Gee.ArrayList<Host.Connection> connections {
			get;
			set;
			default = new Gee.ArrayList<Host.Connection>();
		}
```

#### Serialize — omit (still skip write)
```vala
				case "tree":
				case "connections":
				case "pending-secrets":
				case "need-migrate":
```

#### Deserialize — flag only (property must exist so the key is seen)
```vala
				case "connections":
					this.need_migrate = true;
					value = Value(typeof(Gee.ArrayList));
					value.set_object(this.connections);
					return true;
```

**🚫** Hand-parsing the array in ``deserialize_property`` — migrate re-reads the file.
**🚫** Dropping the ``connections`` property — without it the key is skipped and migrate never runs.
