### Tabs / shortcuts

#### Double-click empty tab bar

- **🔷** `✅` Empty region of the tab bar (where tabs go): **double-click** → open a new terminal (`Host.TabBar` / `win.new-terminal`).

#### Background tab close — animate + cancel

- **🔷** `✅` Closing any tab (selected or background):
  - Keep the **normal title**.
  - **X** → **pause** (cancel); cancel restores X.
  - Fill: **one** orange Overlay child; idle = `visible = false`, `width_request = 1`; closing = visible + width from chip `row.get_width()` × countdown; rest of chip = normal `.host-tab` bg.
  - **Active:** also VTE `close_bar`. **Background:** chip underlay only.

#### New-tab shortcuts (split by kind)

- **🔷** `✔️` Split (was: Ctrl+Shift+T cloned focused kind):
  - **Ctrl+Shift+T** / tab **`+`** → always new **terminal** tab (`win.new-terminal`)
  - **Ctrl+Shift+S** → new **SSH** tab for the focused host (`win.new-ssh`); on Localhost same as **T**

### Connection / LXC

#### LXC host — scan then tick

- **🔷** `⏳` Today: tick “LXC host”, then scan / fetch — pointless order.
- **🔷** `⏳` Wanted: **Scan LXC hosts** button → if scan finds them, it **ticks**.
- **🔷** `⏳` Once ticked: can **re-scan**.
- **🔷** `⏳` Untick → control becomes the **Scan LXC hosts** button again (not tick-then-scan).

#### LXC container — console ↔ attach

- **🔷** `⏳` Right-click an LXC container: toggle between **attach** and **console**.
- **🔷** Container tree context menu: **console** / **attach**; `lxc_enter` default. Lifted from **0.4** Phase 19.
- **🚫** Edit connection on LXC rows (delete-only).

#### SSH options in Edit Connection

- **🔷** Plain “SSH options” text entry: load/save `connection.options`.

- **🚫** Forward agent, “allow remote port connection”, IP protocol — no clear need.
- **🚫** Remote port forwarding / dynamic SOCKS / Ásbrú “advanced” — skip unless asked.
- **🔷** Socks proxy / network settings — very low on the list.

#### Connection dialog layout

- **🔷** One row: connection method + host + port (tighter basic tab).

#### Pick private key

- **🔷** After key login works (follow-on to **Set up SSH key login**), offer **Lock down server (keys only)**.
