### Tabs / shortcuts

#### Double-click empty tab bar

- **🔷** `⏳` Empty region of the tab bar (where tabs go): **double-click** → open a new terminal.

#### Background tab close — animate + cancel

- **🔷** `⏳` Closing a tab that is in the **background**:
  - Animate the tab background.
  - Change its text to **closing**.
  - Change the **X** to a **stop** control so you can cancel the close.

#### New-tab shortcuts (split by kind)

- **🔷** `⏳` Today Ctrl+Shift+T clones the focused kind (terminal → terminal, SSH → SSH).
- **🔷** `⏳` Split:
  - **Ctrl+Shift+T** → new **terminal** tab
  - **Ctrl+Shift+S** → new **SSH** tab

### Connection / LXC

#### LXC host — scan then tick

- **🔷** `⏳` Today: tick “LXC host”, then scan / fetch — pointless order.
- **🔷** `⏳` Wanted: **Scan LXC hosts** button → if scan finds them, it **ticks**.
- **🔷** `⏳` Once ticked: can **re-scan**.
- **🔷** `⏳` Untick → control becomes the **Scan LXC hosts** button again (not tick-then-scan).

#### LXC container — console ↔ attach

- **🔷** `⏳` Right-click an LXC container: toggle between **attach** and **console**.

#### SSH options in Edit Connection

- **🔷** Plain “SSH options” text entry: load/save `connection.options`.
- **🔷** Useful toggles later: fold X11 (`-X` / `-x`), compression (default on?) — low urgency.
- **🚫** Forward agent, “allow remote port connection”, IP protocol — no clear need.
- **🚫** Remote port forwarding / dynamic SOCKS / Ásbrú “advanced” — skip unless asked.
- **🔷** Socks proxy / network settings — very low on the list.

#### Connection dialog layout

- **🔷** One row: connection method + host + port (tighter basic tab).

#### Pick private key

- **🔷** Choose a private key other than the ones we define / auto-create.

#### Lock down server (SSH keys only)

- **🔷** After key login works (follow-on to **Set up SSH key login**), offer **Lock down server (keys only)**.
- **🔷** Guided: verify key auth → show planned `sshd` changes (`PasswordAuthentication no`, etc.) → apply drop-in / config → reload → confirm reconnect still works.
- **🚫** Never silent / never default — easy to lock yourself out.
- **ℹ️** Keep sudo/password in keyring if elevation is still needed after password login is disabled.

#### Per-connection terminal options

- **🔷** Edit prompt/regex (etc.) per connection — interesting later.

#### Other protocols (Ásbrú parity — mostly out)

- **ℹ️** Ásbrú has FTP, RDP, SFTP, serial, Telnet, VNC, WebDAV…
- **🚫** Unlikely we support those; SSH (+ local / LXC) stays the scope unless asked.

#### Remember tree expand / collapse

#### Auto-restore open tabs
