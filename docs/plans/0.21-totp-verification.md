# 0.21 — Auto-fill TOTP verification codes

**Status:** ⏳ proposed

**Pointer:** `docs/guide-to-writing-plans.md` — **Checklist for plans**; Vala via **`docs/coding-standards-router.md`**. Build: **`docs/build-rules.md`**.

**ℹ️** Next number after **0.20** last tab per workspace (`docs/plans/done/0.20-DONE-workspace-last-tab.md`).

**🔷** This repo is **public**. This plan must never contain a TOTP secret, base32 key, live code, or host-specific wrapper name.

Edits are **Remove** / **Replace with** / **Add** from the tree;
verify surrounding context before applying.

---

## Purpose

- **🔷** SSH login already stops on `verification code:` (`WAIT_VERIFICATION_CODE`).
- **🔷** Those numbers are TOTP (Google Authenticator style) from **liboath**, via **`Oath.totp`**. Local wrappers still show the same base32 secret.
- **🔷** Store the **base32 authenticator secret** in **libsecret** (not JSON, not this repo).
- **🔷** When the prompt appears and a secret is **already stored**, generate the current code and **feed it** — no phone.
- **🔷** When the prompt appears and **no** secret is stored, show an **OK / Cancel** dialog for the one-time code. A **blue link** under the field switches that same dialog to paste the authenticator secret (not a second window).
- **⏳** New `Dialog.Verification` (holds the job; `on_ok` / `on_submitted`); `SshLogin.verification()` auto-feeds or presents the dialog; optional field on Edit connection to view/clear; packaging + changelog for liboath.

---

## Current behaviour

- **ℹ️** `Jobs.SshLogin.on_content` matches `verification code:\s*$` (caseless), sets `WAIT_VERIFICATION_CODE`, `present()` + `grab_focus()` — user types in the VTE.
- **ℹ️** `SshLogin.login` / `OpenSession.login` / `SetupKey.run` `continue` on that state; they never `feed_child` a code.
- **ℹ️** Passwords already live in libsecret. `pass` / `passphrase` are skipped in `connections.json`.
- **ℹ️** This machine has **liboath** runtime (`liboath0t64`). Headers / `liboath.pc` come from **`liboath-dev`** (not installed yet). Thin vapi in-tree like `libgcrypt`.
- **ℹ️** Local wrappers are `oathtool -b <base32> --totp`. That `<base32>` is the secret to paste. Do not copy wrappers or keys into the tree.

---

## Proposed behaviour

### Secret storage

- **🔷** libsecret schema **`org.roojs.rooterm.Totp`**, attribute **`uuid`**. Separate from the password secret.
- **🔷** Runtime property `Host.Connection.totp` (empty default). Skip it in JSON like `pass`.
- **🔷** LXC spawn / store uses the **parent** uuid (same as password).
- **💩** Edit connection still has a **Verification secret** row to view/clear (hidden for LXC). Import at the prompt is the first-time path.

### Generate

- **🔷** Link **liboath** (`dependency('liboath')`). Binding is **`vapi/liboath.vala`** (Vala, not a `.c` file). Add **`liboath-dev`** to `docs/build-rules.md`.
- **🔷** RooTerm Vala only calls **`Oath.totp (base32)`** → six-digit string, or empty on failure. Job/dialog never see `void*` / `uint8[]` / `oath_init`.
- **🔷** Binding file: private `[CCode]` to liboath, public **`totp`** in Vala (`init` → decode → generate → `done`).
- **🔷** Same SHA1 / 6 digits / 30s as the local oathtool wrappers.
- **🔷** Empty return → `GLib.warning` in Vala, then the dialog (or VTE focus in `on_submitted`).
- **🔷** Do **not** spawn **oathtool**. Do **not** add a C wrapper file.

### When the prompt appears

- **🔷** Still classified in **`SshLogin.on_content`** (all login jobs inherit it). Login loops already `continue` on `WAIT_VERIFICATION_CODE` — do not add loop cases.
- **🔷** `on_content` only sets the state and calls **`verification()`**.
- **🔷** **`verification()`** auto-feeds when a secret is stored; otherwise presents **`Dialog.Verification(this)`**.
- **🔷** Dialog holds **`Jobs.SshLogin job`**. **`on_submitted`** on the dialog stores / generates / feeds via that job. No `submitted` signal.
- **🔷** One-shot via the existing `current_state != WAIT_VERIFICATION_CODE` guard. Leave that state set after feed so a still-visible prompt cannot re-feed in a loop.
- **🔷** `totp` already loaded → `verification()` generates and `feed_child` (code + newline). Do not open the dialog.
- **🔷** `totp` empty (or generate failed) → `verification()` `present()`s the overlay and opens **`Dialog.Verification(this)`**.
- **🔷** One dialog, two modes — **not** both fields at once, **not** a second dialog.
- **🔷** Default mode: **Code** entry + OK / Cancel. Link under the field: **Set up authenticator secret**.
- **🔷** Link **toggles** the same dialog: hide the code row, show the secret row (password entry), focus it. Link label becomes **Use a one-time code**.
- **🔷** Toggle back: hide secret, show code, link label **Set up authenticator secret** again.
- **🔷** OK in code mode: `on_ok` requires a code, then **`on_submitted(code, "")`** (feed, do not store).
- **🔷** OK in secret mode: `on_ok` requires a secret, then **`on_submitted("", secret)`** (store + generate + feed).
- **🔷** Cancel / close without OK → `grab_focus` the VTE (wired in the dialog ctor from `job`).
- **💩** Link widget: `Gtk.LinkButton` (`activate_link` returns true so it does not open a URI). Blue text, start-aligned, not a second header button.
- **🔷** `auth == "manual"`: still auto-feed / dialog (manual is about not feeding the **password**).
- **🔷** Do not log the secret or the six-digit code (`totp_len` / `code_len` only).
- **💩** Always show the dialog even when totp is stored (pre-fill the generated code, user hits OK) — not this round; skip dialog when we can generate.
- **💩** Wrong code / second `verification code:` prompt: type in the VTE this round (one-shot). Re-open dialog later if that is annoying.

```vala
namespace RooTerm.Dialog
{
	/**
	 * SSH ``verification code:`` prompt. Default: type a one-time code.
	 * A link toggles this same dialog to paste an authenticator secret.
	 */
	public class Verification : Adw.Dialog
	{
		private Gtk.Entry code_entry;
		private Gtk.PasswordEntry secret_entry;
		private Gtk.Box code_box;
		private Gtk.Box secret_box;
		private Gtk.LinkButton mode_link;
		private bool secret_mode;
		private Jobs.SshLogin job;

		/**
		 * Build the verification form (code mode first).
		 *
		 * @param job Login job — connection, VTE, and wait state
		 */
		public Verification(Jobs.SshLogin job)
		{
			this.job = job;
			this.content_width = 440;
			this.title = "Verification code";
			this.secret_mode = false;
			this.closed.connect(() => {
				if (this.job.current_state != Jobs.Job.State.WAIT_VERIFICATION_CODE) {
					return;
				}
				this.job.terminal.terminal.grab_focus();
			});

			this.code_entry = new Gtk.Entry() {
				input_purpose = Gtk.InputPurpose.DIGITS,
				hexpand = true
			};
			this.secret_entry = new Gtk.PasswordEntry() {
				show_peek_icon = true,
				hexpand = true
			};
			this.code_entry.activate.connect(() => {
				this.on_ok();
			});
			this.secret_entry.activate.connect(() => {
				this.on_ok();
			});

			this.code_box = new Gtk.Box(Gtk.Orientation.VERTICAL, 6);
			this.code_box.append(new Gtk.Label("Code") { xalign = 0 });
			this.code_box.append(this.code_entry);

			this.secret_box = new Gtk.Box(Gtk.Orientation.VERTICAL, 6) {
				visible = false
			};
			this.secret_box.append(new Gtk.Label("Authenticator secret") { xalign = 0 });
			this.secret_box.append(this.secret_entry);

			this.mode_link = new Gtk.LinkButton.with_label("#", "Set up authenticator secret") {
				halign = Gtk.Align.START
			};
			this.mode_link.activate_link.connect(() => {
				this.secret_mode = !this.secret_mode;
				this.code_box.visible = !this.secret_mode;
				this.secret_box.visible = this.secret_mode;
				this.mode_link.label = this.secret_mode
					? "Use a one-time code"
					: "Set up authenticator secret";
				if (this.secret_mode) {
					this.secret_entry.grab_focus();
					return true;
				}
				this.code_entry.grab_focus();
				return true;
			});

			var box = new Gtk.Box(Gtk.Orientation.VERTICAL, 10) {
				margin_top = 16,
				margin_bottom = 16,
				margin_start = 16,
				margin_end = 16
			};
			box.append(this.code_box);
			box.append(this.secret_box);
			box.append(this.mode_link);

			var cancel = new Gtk.Button.with_label("Cancel");
			cancel.clicked.connect(() => {
				this.close();
			});
			var ok = new Gtk.Button.with_label("OK") {
				css_classes = { "suggested-action" }
			};
			ok.clicked.connect(() => {
				this.on_ok();
			});

			var header = new Adw.HeaderBar() {
				show_start_title_buttons = false,
				show_end_title_buttons = false
			};
			header.pack_start(cancel);
			header.pack_end(ok);
			var toolbar = new Adw.ToolbarView();
			toolbar.add_top_bar(header);
			toolbar.content = box;
			this.child = toolbar;
		}

		/**
		 * Require the visible field, then {@link on_submitted}.
		 */
		private void on_ok()
		{
			if (this.secret_mode) {
				var secret = this.secret_entry.text.strip();
				if (secret.length == 0) {
					this.secret_entry.grab_focus();
					return;
				}
				this.on_submitted("", secret);
				this.close();
				return;
			}
			var code = this.code_entry.text.strip();
			if (code.length == 0) {
				this.code_entry.grab_focus();
				return;
			}
			this.on_submitted(code, "");
			this.close();
		}

		/**
		 * Store an imported secret if any, then feed a code into the job VTE.
		 *
		 * @param code Typed one-time code, or empty in secret mode
		 * @param secret Authenticator secret to store, or empty in code mode
		 */
		private void on_submitted(string code, string secret)
		{
			var feed = code;
			if (secret.length > 0) {
				var totp_uuid = this.job.connection.uuid;
				if (this.job.connection.kind == Host.ConnectionKind.LXC
						&& this.job.connection.parent_uuid.length > 0) {
					totp_uuid = this.job.connection.parent_uuid;
				}
				this.job.connection.totp = secret;
				try {
					Secret.password_store_sync(
						new Secret.Schema(
							"org.roojs.rooterm.Totp", Secret.SchemaFlags.NONE,
							"uuid", Secret.SchemaAttributeType.STRING
						),
						Secret.COLLECTION_DEFAULT,
						"RooTerm TOTP " + totp_uuid,
						secret,
						null,
						"uuid", totp_uuid
					);
				} catch (GLib.Error e) {
					GLib.warning("totp store failed uuid=%s: %s", totp_uuid, e.message);
				}
			}
			if (feed.length > 0) {
				GLib.debug("login feed totp name=%s code_len=%d",
					this.job.connection.name, feed.length);
				this.job.terminal.terminal.feed_child((feed + "\n").data);
				return;
			}
			if (secret.length == 0) {
				this.job.terminal.terminal.grab_focus();
				return;
			}
			feed = Oath.totp(secret);
			if (feed.length == 0) {
				GLib.warning("totp generate empty name=%s", this.job.connection.name);
				this.job.terminal.terminal.grab_focus();
				return;
			}
			if (feed.length == 0) {
				this.job.terminal.terminal.grab_focus();
				return;
			}
			GLib.debug("login feed totp name=%s code_len=%d",
				this.job.connection.name, feed.length);
			this.job.terminal.terminal.feed_child((feed + "\n").data);
		}
	}
}
```

#### Add — new file `vapi/liboath.vala`

Private C bindings; public **`Oath.totp`**. Binary arrays stay in this file. Empty string on failure. No `else`.

```vala
[CCode (cheader_filename = "liboath/oath.h")]
namespace Oath
{
	[CCode (cname = "oath_init")]
	private static int init();

	[CCode (cname = "oath_done")]
	private static int done();

	[CCode (cname = "oath_base32_decode")]
	private static int base32_decode(
		string input,
		size_t inlen,
		[CCode (array_length_type = "size_t")] out uint8[] output
	);

	[CCode (cname = "oath_totp_generate")]
	private static int totp_generate(
		[CCode (array_length_type = "size_t")] uint8[] secret,
		time_t now,
		uint time_step_size,
		time_t start_offset,
		uint digits,
		[CCode (array_length = false)] uint8[] output_otp
	);

	/**
	 * Six-digit TOTP from a base32 secret. Empty on failure.
	 */
	public static string totp(string secret)
	{
		if (secret.length == 0) {
			return "";
		}
		if (init() != 0) {
			return "";
		}
		uint8[] binary;
		if (base32_decode(secret, secret.length, out binary) != 0) {
			done();
			return "";
		}
		uint8[] otp = new uint8[7];
		var rc = totp_generate(binary, Posix.time(null), 0, 0, 6, otp);
		done();
		if (rc != 0) {
			return "";
		}
		return (string) otp;
	}
}
```

```vala
			this.totp_entry.text = totp_text;
			this.totp_box.visible = this.target.kind != Host.ConnectionKind.LXC;
```
